# 《诡秘之主》与《宿命之环》阅读资料库

本仓库保存两部小说的章节笔记、伏笔审查和证据定位，帮助读者或 AI 按卷章检索剧情、人物状态、因果和世界规则。**含两部全书剧透。它是仍在核验的工作资料库，不是全部内容已经验证的百科。** 不包含小说全文，也不包含 Minecraft 整合包。

## 给 AI 的阅读顺序

1. 阅读 [资料状态与使用边界](资料状态与使用边界.md)，区分“笔记记录已到文件末尾”和“内容已独立验证”。
2. 阅读 [当前审查报告](伏笔审查/最终审查报告.md)、[旧笔记修正清单](伏笔审查/旧笔记修正清单.md)及[最终修订说明](伏笔审查/最终修订说明.md)。
3. 用 [章节笔记索引](阅读笔记索引.md) 从《诡秘之主》第一部到第八部，再到《宿命之环》第一卷至第八卷顺序查阅。索引中的补核文件与章节笔记相互补充。
4. 具体问题查 [伏笔总台账](伏笔审查/伏笔总台账.md)、[开放问题](伏笔审查/仍未揭示与开放问题.md)和 [逐项核验队列](伏笔审查/证据记录/旧索引子项核验队列.tsv)。最后回到对应证据记录，不仅看状态字母。

一次浏览仓库链接不会自动读完全部资料。回答某个问题时，应明确实际读取了哪些卷章和证据；没有读取的部分不要声称已经掌握。

## 内容优先级

当前修正与具体证据 > 同一问题的早期笔记；但新文件也不是自动正确。发现证据冲突，应保留双方、注明叙述者与卷章并标记待核，不能只凭文件较新就覆盖原著。

- 原著中客观发生的事件、梦境/幻象、人物陈述、人物推理、整理者推测、后期揭示须分开。
- 区分事件实际发生顺序与读者获知顺序，不把后期知识倒灌给前期人物。
- 取得材料、满足条件、开始仪式和完成晋升是不同状态。
- H 表示核验尚未完成，不表示原著没有答案。候选主题映射和关键词命中不等于伏笔回收证据。
- 设计改编与原著事实须分开；本仓库未纳入游戏玩家身份、任务机制等设计稿。

## 目录

- `阅读笔记/`：历史阅读过程中的详细笔记，保留原文件名以便证据回溯；并非逐句验证后的成稿。
- `伏笔审查/`：当前报告、修正清单、主题台账、证据和待核验队列。
- `归档/`：旧索引，仅用于来源追溯，不作为当前结论。
- [来源与版本](来源与版本.json)：此次入库文件的 SHA-256 和来源版本信息。
- [引文与权利说明](引文与权利说明.md)：原著引文与整理材料的边界。

本仓库目前没有经过全量核验的统一剧情总纲、全时期事件表、人物状态表和力量规则表。详细笔记可以支持定向查阅，但不能承诺任意 AI 只读入口就能完整理解两部小说。
