# 《宿命之环》第一卷《梦魇》第97—98章 考据

批次区间：[342482, 349684)，下一位置为第九十九章《客人》。分两次提取（097、098），正文完整返回，无截断。**本批含“猎人”魔药的彻底消化、一枚无法直视的“心脏”，以及一个极重的转折：四旬节结束，全村都成了“披着人皮的怪物”。**

## 一、勇气：“猎人”魔药彻底消化（第九十七章，极重要）

- **【本章的核心：一条通往“勇气”的领悟（极重要）】**：
  - 他在重伤中反思（极重要）：“‘**“猎人”不仅要小心，要谨慎，要冷静，要耐心，要懂得利用环境，发挥自身优势，而且还要具备勇气。**’”
  - **【四种勇气（极重要）】**：“‘**遭遇意外状况时敢于直面的勇气，出现极大危机时永不放弃的勇气，没有退路时能下定决心的勇气，向着死亡去寻求生路的勇气……**’”
  - **【结果（极重要）】**：“‘**这一个个念头在卢米安脑海内闪过，让他不由自主分心的同时，骤然产生了体内“猎人”魔药已彻底消化的感觉：那就像是有什么屏障被完全打破，像是有一点点火星与身体每个部位结合在了一起。**’”“‘**卢米安残存的失控迹象随之消失大半，状态瞬间好了不少。**’”“‘**确实消化了……**’”“‘**这意味着他做好了服食下一份魔药的准备。**’”
    - **一个极重要的效果（极重要）**：**“猎人”魔药的彻底消化使残存的失控迹象消失大半**——即**消化/扮演本身就是压制失控的手段**
- **【“纵火家”主材料的析出（极重要）】**：
  - 等待的时长（极重要）：“‘**和猎枪怪物迅速就有相应变化不同，卢米安这次等了足足半个小时**’”
  - **它的形态（极重要）**：“‘**一点点赤红火星般的光芒从怪物的体内飞了出来。它们仿佛一大群萤火虫，将那具尸体严严实实地围住，然后慢慢往内收缩，凝聚成一颗类似心脏的赤红物品。那“心脏”缓慢地膨胀和收缩着，表面布满了密集的小孔，每一个小孔都有微不可见的火焰往外喷薄。**’”
  - **它的危险（极重要）**：“‘**炽烈的灼烧感从他的掌心传入了脑海，让他下意识就想丢掉那颗“心脏”**’”“‘**他尝试着用布条包裹那颗“心脏”，结果布条逐渐燃烧起来，化成了灰烬。**’”
  - **他的处置（极重要）**：“‘**卢米安挖掘周围的泥土，把它们填入布袋里面……他才拿起那颗有细微火焰缭绕的“心脏”，将它丢了进去。**’”“‘**继续往袋子里塞起泥土，直至“心脏”前后左右上下都被这不易燃烧的褐色材料填满，一层又一层。**’”
- **【一个极重要的难题（极重要）】**：
  - “‘**我只有序列9，而这是对应序列7“纵火家”的主材料，我总不能直接升序列7吧？这会失控的！**’”
  - **【他的预期落空（极重要）】**：“‘**我原本还以为，火焰怪物会析出一份“纵火家”非凡特性、一份“挑衅者”非凡特性和一份“猎人”非凡特性，结果是混合在一起的……**’”
- **【他在现实中的状态（极重要）】**：
  - “‘**卢米安看到镜中的自己脸色异常青白，多有火焰燎过留下的痕迹，身上多处皮肤残留着若有似无的银黑色斑块。他蓝色的眼眸内，虚幻的银白隐隐凸显，自我缠绕，染着黑色。这是受了重伤又差点失控的外在表现。**’”
  - **一段极重要的实力复盘（极重要）**：“‘**要不是在这片梦境废墟有很强的“主场优势”，要不是获得了“堕落水银”，拥有了“隐身”能力，卢米安几乎没希望猎杀那个火焰怪物。**’”
- **【本批最动人的段落（人物素材，极重要）】**：
  - 奥萝尔的话（极重要）：“‘**你快一个小时前浑身抽搐，手脚乱动，把我给踢醒了。**’”
  - **他的追问与她的回答（极重要）**：“‘**你其实不是被我踢醒，而是一直没睡吧？**’”“‘**我原本是这么打算的，可想到你蹲那个怪物不知道要蹲多久，我又刚值完夜，如果不补一会儿觉，到了后半截精神肯定恍惚，反而容易出现失误，来不及把你叫醒。**’”“‘**所以，我最终决定一边把手放在你身上，一边抓紧时间睡一会儿。这样一来，你一有什么动静，我就能感应到，迅速醒过来，呵呵，我确实被你踢了一脚！**’”
    - **她小腿上的淤青（极重要）**：“‘**她边说边指了指自己的右小腿，那里有一块明显的淤青。**’”
  - **卢米安的反应（极重要）**：“‘**卢米安突然感觉梦里的艰难、痛苦、挣扎和差点死去的恐惧在这一刻都被心底涌现出来的暖流冲散了，淹没了。**’”
- **【关于如何分离非凡特性（极重要）】**：
  - 奥萝尔（极重要）：“‘**我不知道怎么分离，我只是听人提过，类似情况可能得请高位格的非凡者帮忙。**’”
  - **卢米安能想到的三位“半神”级（极重要）**：“‘**那位神秘的女士、普阿利斯夫人和墓室棺材内躺着的那位。**’”
  - **奥萝尔的预测（极重要）**：“‘**我怀疑那位神秘的女士很快就会来找你，提供一定的帮助，她总是在你成长的关键节点出现，这次应该也不例外，毕竟循环还没有解除，梦境废墟的秘密也还没有解开。**’”
- **【一个极重要的体系知识：序列7以下可不配魔药（极重要）】**：
  - “‘**不是不需要，而是序列7以下，可以靠强行服食主材料来晋升。**’”
  - **风险（极重要）**：“‘**在前些年，这么做大概率失控，但近几年，序列9和序列8的非凡特性确实可以直接用，只是比调配成魔药危险大概百分之二三十。**’”
  - **其依据（极重要）**：“‘**嗯，这是我们会长“甘道夫”做的调查结论。**’”
  - **卢米安的特殊（极重要）**：“‘**对正常非凡者来说，魔药配方倒是问题不大，但你不一样，你体内封印着污染，稍有问题就可能失控，还是需要完整的、正确的“挑衅者”魔药配方。**’”
- **章末（极重要）**：“‘**四旬节开始了，“春天精灵”巡游到这边了。**’”

## 二、庆典之后：全村都成了“披着人皮的怪物”（第九十八章，极重要）

- **【四旬节的巡游（极重要）】**：
  - “‘**一群年轻人簇拥着阿娃，边唱边跳来到了卢米安家外面。贝里家的小纪尧姆走至门口，砰砰拍起大门。**’”
  - 小纪尧姆（极重要）：“‘**他是卢米安、雷蒙德和阿娃的朋友，长着微卷的棕发，脸上有明显的雀斑，蓝色的眼睛比正常人偏小，仿佛总是眯着。**’”
  - **奥萝尔的应对（人物素材，极重要）**：“‘**她挽起了金发，穿着相当正式的荷叶边浅色立领长裙，整个人精神饱满，脸上光彩流淌，完全看不出昨晚值了大半个夜晚上午又没有睡好的疲态。**’”
  - **小纪尧姆的关心（极重要）**：“‘**卢米安呢？这两天都没有看到他，他不参加四旬节庆典了？**’”——“‘**他生病了。**’”“‘**如果他不会生病，我反而害怕。人类都会生病。**’”
    - 他的留言（极重要）：“‘**给卢米安说，四旬节之后，我来看望他！**’”
  - **奥萝尔的判断（极重要）**：“‘**他们现在还很正常，但不知道庆典结束时会变成什么样子。**’”
- **【正午十二点后的观察（极重要）】**：
  - “‘**天空湛蓝，白云朵朵，阳光明媚，没有他想象中的乌云、雾气和昏暗的光线。**’”
  - **莉雅的占卜（极重要）**：“‘**我们已经处在危险之中，而且是长期性的危险，但目前属于可以应付的程度。**’”
  - **莱恩的一句“乌鸦嘴”（人物素材，极重要）**：“‘**到第十二夜前，如果一直只有这种程度就好了。**’”
    - **奥萝尔的欲言又止（极重要）**：“‘**不好意思对这位“机械之心”的“黎明骑士”说不要讲类似的话语，这很容易带来相反的效果。**’”
  - **卢米安的谚语（极重要）**：“‘**我们达列日地区有一句谚语，“吉凶全由命，事前早注定”，我们再怎么担心也改变不了接下来的事情。**’”
    - **他没说出口的（极重要）**：“‘**唯一能做的就是鼓起勇气去面对。**’”
- **【一个极关键的观察：路易斯·贝德克（极重要）】**：
  - **来访者（极重要）**：“‘**拉动门铃的是一个男人，他们的邻居，路易斯·贝德克。**’”“‘**黑发蓝眼，四十多岁，年轻时在田地收割小麦时受过伤，左手只剩下三根指头。**’”
  - 他的请求（极重要）：“‘**我想借你们家烤炉，四旬节了，得给孩子们烤些新鲜的面包。**’”
  - **他的期待（极重要）**：“‘**今年要是丰收，应该会做不少熏肉。**’”“‘**他眼睛里满是期待，似乎觉得丰收是必然会来的事情。**’”
  - **【本批最恐怖的细节（极重要）】**：“‘**路易斯·贝德克竟没有看莱恩、莉雅和瓦伦泰一眼，仿佛他们根本不存在！**’”
  - **奥萝尔的解释（极重要）**：“‘**这就像一个已经变成怪物的人在努力地装出自己很正常，但只要遇到超过原本记忆的事情，他们就会表现出明显的异常，或是直接忽视掉。**’”
    - **与米歇尔的呼应（极重要）**：“‘**他刚开始的时候看起来还好，到了最近，只剩下吃饭、睡觉等日常行为和让人祷告的渴望，其余的一切全部无视！**’”
  - **一句话总结（极重要）**：“‘**这很正常，这很不正常。**’”
- **【一个极精彩的细节：路过者的瞬间变脸（极重要）】**：
  - “‘**其中一个……皮埃尔·纪尧姆。他正和他的同伴聊着天，笑得非常开心，就像在讨论四旬节庆典的热闹之处。**’”
  - **【关键（极重要）】**：“‘**越过卢米安家门口时，他们齐刷刷侧头，望向屋内，表情皆异常阴郁。只看了一秒，他们就收回了视线，脸上又堆满了笑容，继续起刚才的话题。**’”“‘**如果不是卢米安他们在有人路过时，一直观察着外面，肯定发现不了那短短一瞬间的神情变化。**’”
- **【奥萝尔的结论（极重要）】**：“‘**这已经不是在被怪物一点点取代，我怀疑整个村子，除了我们，都是披着人皮的怪物了。**’”
  - 莱恩的提醒（极重要）：“‘**接下来会一天比一天难熬，大家坚持住。**’”
- **【关于“救”的可能（极重要）】**：
  - 卢米安的问题：“‘**这样的人，如果想救，该怎么救？**’”
  - **瓦伦泰的回答（极重要）**：“‘**我唯一能想到的是“净化”。但如果异常已经和人类本身紧密结合，最终的结果可能是一起被净化。**’”
- **【姐弟的准备（极重要）】**：
  - 卢米安想去老酒馆找那位女士，奥萝尔的顾虑（极重要）：“‘**现在的村里，每一个人都可能是怪物，一旦出去，会非常危险。**’”“‘**再等等吧，明天上午那位神秘的女士要是还没有出现，我下午就陪你去老酒馆。**’”
- **【章末的转折（极重要）】**：
  - “‘**弥漫着淡薄灰雾的卧室内，卢米安睁开了眼睛。他翻身坐起，检查了下身体，发现之前那么重的伤已经完全好了。**’”
  - **【关键（极重要）】**：“‘**他正要感慨一句，霍然听到了“叮铃铃”“叮铃铃”的声音。“有人在拉门铃？”**’”“‘**刚走出一步，他整个人突然僵住了。这可是在梦境废墟里！怎么可能有人上门拜访？**’”

## 三、待核对／未解线索（不做断言）

- **梦境废墟里是谁在拉门铃**（本批最大的悬念）。
- 如何从“纵火家”非凡特性中**分离出“挑衅者”**的那一份。
- 全村异化者**能否被救**。
- 那位神秘的女士是否会主动上门。

## 四、整合包可用要点小结

- **【“猎人”的完整信条（极重要）】**：**不仅要小心、谨慎、冷静、耐心、懂得利用环境与发挥优势，还要具备“勇气”**——**四种勇气：遭遇意外时敢于直面的勇气、出现极大危机时永不放弃的勇气、没有退路时能下定决心的勇气、向着死亡去寻求生路的勇气**。**悟到这一层后，“猎人”魔药彻底消化**，**残存的失控迹象随之消失大半**。
- **【序列7以下可不配魔药（极重要）】**：**序列7以下可以靠强行服食主材料晋升**；**前些年这么做大概率失控，但近几年序列9、8的非凡特性确实可直接用，只是比调配成魔药危险约百分之二三十**（**结论出自会长“甘道夫”的调查**）；**卢米安因体内封印污染，必须用完整正确的魔药配方。**
- **【“纵火家”非凡特性（极重要）】**：**需等约半小时才析出**；形态为**由赤红火星光芒收缩凝聚而成、类似心脏的赤红物品，缓慢膨胀收缩、表面布满密集小孔，每孔都有微不可见火焰喷薄**；**触之灼烧，布条会被烧成灰烬**，**只能以泥土层层包裹**；**且“纵火家／挑衅者／猎人”三份特性是混合在一起的，须请高位格非凡者帮助分离**。
- **【四旬节之后的村庄（极重要）】**：**除卢米安一行外，全村人几乎都成了“披着人皮的怪物”**——**表现是“努力装出正常”，但遇到超出原本记忆的事物便会“明显异常或直接忽视”**（如路易斯·贝德克**对三名外乡人视若无睹**），且**会在无人注意的一瞬间露出阴郁森冷的神情**；**瓦伦泰认为唯一的救法是“净化”，但若异常已与本人紧密结合，结果可能是“一起被净化”。**
- **【达列日的谚语（极重要）】**：“**吉凶全由命，事前早注定**”。
- **人物与地点**：科尔杜村（卢米安家、邻居）、梦境废墟；**路易斯·贝德克（邻居）**、**小纪尧姆（纪尧姆·贝里）**、**阿娃**、**皮埃尔·纪尧姆**、莉雅／莱恩／瓦伦泰、奥萝尔。
