# 《诡秘之主》第二部第226—228章考据

- 连续正文区间：`[1556134, 1566518)`；下一章为第二百二十九章《探索任务》。
- 【王室／人物关系】埃德萨克承认曾将奥黛丽视为理想婚配对象，但现在爱上一名具有独特气质与阅历的女性；结合塔利姆此前故事及庄园禁足女子，克莱恩判断故事主角就是王子，当前仍属高度可信推断。王室直系配偶按惯例只能是贵族女性。
- 【任务与联络】克莱恩被迫接受塔利姆案，要求死者头发或血肉及随身物品用于神秘学调查。王子将隐秘租下明斯克街13号作为信件联络点，并承诺按贡献付酬、查清真相则给足以养老的报酬；这也使王室力量直接进入克莱恩住所相邻位置。
- 【人物状态】奥黛丽从心理炼金会预支获得序列7“心理医生”配方，组织未立即要求贡献，基于其偿付能力给予信用。克莱恩因案件风险更迫切晋升“无面人”，不再只等待机械之心探索陵墓。
- 【罗塞尔日记／门先生讲述】门先生称若用塔罗牌代表黑夜女神应选“星星”而非“月亮”，并称“月亮”序列0当时空缺。克莱恩据此提出原始月亮可能是其他神灵化身、序列1或相应封印物、乃至唯一性回应等猜测，均未证实。
- 【第四纪史料／角色讲述】图铎王朝五大天使家族为亚伯拉罕、安提哥努斯、阿蒙、塔玛拉、雅各；所罗门阵营有查拉图、索罗亚斯德；特伦索斯特阵营有奥古斯都、索伦、艾因霍恩、卡斯蒂亚；另有安德雷拉德、贝利亚，以及源于真神、层级更高的魔女家族。此信息由门先生讲给罗塞尔，再见于日记。
- 【历史伏笔】罗塞尔后期挣扎时未再提门先生，说明两者关系后续发生变化。日记还记载弗洛朗像保留记忆与特征的“精神缝合怪”；古籍称原初魔女名为男性名“奇克”，但罗塞尔怀疑古籍真伪，不能直接定论其原初性别。
- 【交易与塔罗会渠道】阿尔杰以1200镑卖出狼人特性，按约保留200镑，并找到每根100镑的深海娜迦头发；克莱恩要求五根加500镑余额。奥黛丽求购镜龙双眼、50毫升血液和长者之树果实；佛尔思与戴里克分别提供亚伯拉罕、白银城渠道。塔罗会正式获得心理炼金会和亚伯拉罕两条新资源渠道。
- 【信息安全】克莱恩把“黄昏隐士会名称可能触发感知”的推测包装为愚者警告，以“凡有言，必被知”要求成员在外界不说不写。成员据此执行，但这一规则当前仍源于对罗塞尔谨慎行为的推断，尚无客观验证。
- 【成员状态】戴里克已完成多次巡逻、未见异常，自认监控趋缓；佛尔思因愚者干扰占卜而承诺十页日记。章末佛尔思询问同层次非凡特性积累过多的解决办法，指向重复服药后果，答案待下章。
