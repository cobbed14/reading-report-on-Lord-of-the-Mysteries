# 第一部第123—126章

连续阅读区间 [438452, 452437)，GBK 解码字符；未截断。

- 特莉丝用粉末咒文隐身、匕首袭杀弗莱的画面是邓恩诱导梦境，弗莱并未实际被刺。清醒后她以镜面替身挡枪，跑到一楼中断仪式带走骨像，造成阴冷风、幽影及植物帘布异动，借混乱再隐身，绕过灵视逃河中。隐身、替身、仪式破坏的条件与连续性不可简化为无限无敌。
- 祭台骨像长发带眼、似蛇触手，木偶写目标名；邓恩后来判定诅咒廷根范围内全部苜蓿号幸存者，未波及所有地域幸存者。仪式已破坏，未实施成功的大规模诅咒不可写成既成灾难。
- 特莉丝用花朵取伦纳德血，黑焰焚花施诅咒；伦纳德似侧听后自拔指甲、加血发另作替代，烧掉替物避开。其知识来源未揭示，不能教成所有低序列通用天赋。队长判断敌人至少序列7。
- 克莱恩事后受召接近，先占卜歌声是否幻觉；幽影仍有主动趋近活人倾向，伦纳德诗歌及女神仪式安抚。弗莱被当同类并不等于能完成所有安魂仪式。残灵因仪式反噬缺少有用记忆，通灵没有自动提供凶手。
- 二楼破镜仪式短暂复原过去一月映照人物，形貌模糊；克莱恩梦境回忆连接此前街头及地下市场年轻女士。队友起初认为同伙/姐妹，伦纳德提出特里斯已变女，结合占卜干扰等支持。第126章灰雾占卜让克莱恩完全确认；魔药为何变性及具体序列规则仍待后文，不提前补全。
- 火炮覆盖是克莱恩事后提出的假设方案，没有实际实施；邓恩补充必须先确认暴力毁祭台不会造成更大后果。普通军队与非凡协作存在保密习惯和反噬评估限制，不可只按伤害数值计算。
- 灰雾梦境见特莉丝登车，克莱恩误认正在发生；次日意识到当前客车几乎不夜行，才认出未来画面，请伦纳德以可靠情报掩护报告邓恩。灰雾主要排干扰，未使其具备无限精度；梦境无法辨车次，灵摆逐一排除也不会自动补足有效信息。
- 叙述显示特莉丝先沿河至维尼亚镇（往贝克兰德第一个站）上车，已电报警告廷根同伴，以入室盗窃财物买票，并计划三站后换方式，故不能把预见登车当廷根站现场抓获。
- 周四上午老尼尔说占卜非万能、容易错解，克莱恩结合自身教训领悟，正式彻底消化占卜家；此处首次明确完成，不等于已服小丑晋升。短暂感知虚幻星辰及饥渴不能直接下定高阶机制解释。
- 警方调两名曾接触非凡事件警员做文职获批准，尚未描述报到；技术学院暑假只在七月末八月初两周，梅丽莎已复课。诗歌注释丁尼生《悼念集》十一、飞白译已阅读，未抄录。

回填：第102章地下市场甜美女士与更早街头女士现由回忆确认是特莉丝；先前对特里斯逃离廷根的推测在当时错误，变化身份造成线索中断。新待查：廷根同伴是谁、骨像尊名、诅咒详细机制、追捕后续与晋升申请。
