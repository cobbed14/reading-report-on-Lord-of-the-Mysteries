# 《诡秘之主》第四部《不死者》第41—44章 考据

批次区间：[2727913, 2741294)，下一位置为第四十五章《丧心病狂的配置》。四章正文完整返回，无截断。

## 威廉·赛克斯之死与警察上门（第41章）

- 瓦尔特对威廉·赛克斯的介绍（未做隐瞒）：“我在康纳德子爵家做事的时候，曾经见过他。**他服务于一位王室成员，之前的拉斯廷伯爵，埃德萨克王子。**”
- 克莱恩的判断与克制：威廉在埃德萨克王子身亡后居然过得不错、不知又担任了哪个庄园的执事，“也许他清楚些秘密”；但他决定**暂时忍耐**——若威廉真知道点什么，王室那个派系不会放着不管，或者他本身就属于那个派系，**调查他会是一件相当危险的事情**；不能委托佛尔思、埃姆林或休（会给他们带来危险），莎伦能力足够但“很可能导致她现在的安稳生活被破坏”，最好的办法还是上侠盗“黑皇帝”，可窃取安提哥努斯家族笔记前，他对大雾霾事件的调查“希望仅局限于外围，不惊动任何人，不带来意外的变化”。
- **警察上门**：两位穿黑白格制服的警察（一位高级督察、一位警长——后者是位很英气的女士）。
  - 补充设定：**由于黑夜女神教会的关系，鲁恩警察系统内有为数不少的女警，但因其余信仰、社会思潮等各方面的影响，她们在升职和岗位上仍受到一定程度的歧视，大部分以内部文员为主，上升空间也存在隐形天花板**。
  - 高级督察通报：**威廉·赛克斯死了，死于王国博物馆附近的一家旅馆内**，死因比较复杂、不排除被人谋杀的可能。
  - 其女伴（情妇）离开旅馆时他还活着（旅馆侍者可确定，因为他们后来送过红酒）。
  - 克莱恩提供不在场证明：离开王国博物馆后直接回家、午餐、睡觉、上课，仆人、邻居、文学鉴赏老师均可证明；并让瓦尔特与仆人们接受询问。两位警官走访周围邻居后离开。
- **瓦尔特夜行（重要）**：夜里克莱恩灵性触动，看见**管家瓦尔特从花园小径到外墙翻出去**、沿街道阴影来到**之前海柔尔进入过的下水道入口**、移开井盖爬下并复原。
  - 他的判断：“身手敏捷，动作流畅，不是久经训练的人，就是低序列非凡者”；并推断“之前的深夜里，管家先生应该没有做过，否则我的灵性肯定会有预警，毕竟是从我的‘领地’离开……这说明他在别的地方、在成为我管家前，经常有类似的行动”。
  - 他操纵塞尼奥尔跟踪（注意“希望不要超过100米，否则我也得进下水道了”）。
- **下水道内的对话（揭开“额外展开”）**：瓦尔特前行十来米后拐入更僻静更阴森的通道（墙上地面多有苔藓和肮脏事物），停下与一位虚弱沙哑的女声对话：
  - 瓦尔特：“你为什么这么冲动？为什么不等更好的机会？”
  - 女声：“这就是最好的机会。等他回到那个庄园，不知道多久才会再出来。”
  - 瓦尔特：“可你为什么还会受这么严重的伤？”
  - 女声：“**威廉·赛克斯比你，也比我，想象得更强，大概也只有这样，才符合他暗中的身份。不管怎么样，我终于从他那里得到了线索，这么久过去，总算有接近真相的机会了。**”
  - 女声：“**我已经将灵魂卖给了邪神，接下来人生唯一的意义只有复仇。**”
  - 瓦尔特：“你继续躲在这里，我会给你准备食物，直到你恢复。如果有意外，还是用老办法联络我。”
  - 女声：“他活着的时候，有许多自称忠诚的下属，他死亡后，却只有少数几个人还记得他，还愿意为他冒险，**你是最让我意外的**。”
  - 瓦尔特：“**他是第一个给我那样待遇的贵族，也是我真正想效忠的人。**”
- 克莱恩的解读：**埃德萨克王子死后，少数忠于他的人在暗中调查他自杀的真相，瓦尔特就是其中之一**（主要负责明面上的情报搜集，并利用自己的身份提供一些救助）——这应该就是“魔镜”阿罗德斯提过的**额外展开**。
- 那位女子的真容：**脸蛋略圆、眼睛细长、气质温和、甜美暗藏，是极出色极有魅惑力的少女**——**特莉丝！特莉丝奇克！**

## 特莉丝的调查与海柔尔的遇险（第42章）

- 克莱恩的震惊：她还没死？逃出来了？还想着帮埃德萨克王子复仇？（他回想大雾霾事件前特莉丝迫不及待想摆脱埃德萨克王子的控制、摆脱幕后黑手对她命运的操纵、只觉日常生活充满痛苦，吐槽“这样一位原本是男人的魔女会为了帮埃德萨克王子复仇而将灵魂卖给邪神？这什么三流言情小说的桥段！”）
- **海柔尔的遇险与自救（重要，印证其项链能力）**：
  - 她从马赫特议员家翻出、来到下水道入口一气呵成爬下；前进途中突然背后发冷、脊椎生寒、汗毛立起，仿佛坠入表面结冰的河流，“大量的阴冷迅速占据了自己的身体”；她惊恐地发现自己**主动往另一个方向迈步走向有铁制管道的墙边，而这一切与她的意志无关**。
  - 自救过程：把本身能掌控的灵性全部灌注往脖子上的**项链**（**串着七枚翠绿通透的石头，彼此隔着同等的距离，周围镶嵌着一圈细小的钻石，在绝对黑暗的环境里依旧流淌着细微的荧光**）；第一枚石头亮起（翠绿光芒）→ 靠向墙边的动作停顿、双脚别扭地往前迈又收回、体内阴冷出现短暂呆滞；她随即点亮另一枚石头，**右手抬起对准自己、腕部猛地一扭**，脑海中多了些神秘的符号和花纹、灵性和声带也有一定临时的改变——**她窃取到了“怨魂尖啸”这个非凡能力**。
  - 但她刚要张嘴，就**双手失控、狠狠用力捂住了自己的嘴巴**，尖啸变成只存在于口腔内的呜咽；双脚轻巧迈步到墙边、拐入岔路、蹲到纯粹的黑暗里；竭力挣扎毫无用处，连再次激发项链都难以办到；**深棕色眼眸睁得极大，充满恐惧和不甘，两滴晶莹的泪水缓慢滑落**。
  - 瓦尔特从另一条岔路出来返回入口、敏捷攀爬往上、悄然翻回道恩·唐泰斯府邸——**海柔尔随即找回对身体的控制权，那可怕的阴冷全部消失**。
  - 她的撤离：先诧异地抬双手用夜视查看，再惊恐地左右张望（仿佛下水道黑暗里藏着数不清的怪物）；随后摸着项链、小心翼翼站起、靠近入口（**没有惊慌失措地狂奔，时刻戒备来自黑暗深处的袭击**）；回到伯克伦德街后才加快脚步，跑到一半又折返、紧张慌乱地把井盖移回合拢状态；最后沿街道阴影回到自家花园、借助煤气和自来水管道进入卧室阳台；直到此时才真正有了额外思考能力、身体渐渐出现明显的颤栗；她抬左臂想用衣物擦脸，途中停顿、改为从衣兜掏出手帕。
  - 克莱恩评价：“**海柔尔还是有基本的应对能力，不是纯粹的菜鸟。**”
- **与特莉丝的首次交锋与谈判**：
  - 特莉丝察觉海柔尔的事并发现了“怨魂”；塞尼奥尔现身，特莉丝说“看来你没有恶意。那位小姐运气还不错。”塞尼奥尔答“也许只是杀她会有更大的麻烦。”
  - 克莱恩的真实打算：他很想举报特莉丝（清楚她做过哪些恶事——**教唆“苜蓿号”的乘客与船员在海上自相残杀、让一条条无辜的生命提前逝去**），但发现她在调查埃德萨克王子死亡之谜后有了新打算——**驱使这位魔女在这件事上与她做有限度的合作**；理由是**埃德萨克王子死亡之谜几乎就等于贝克兰德大雾霾事件的真相**，让别人卷入会让他愧疚、害怕他们因此受伤甚至死去，而让特莉丝去做“就不存在这种心理负担，她所犯下的罪行早就该让她进入地狱了”；但他也提醒自己要提防她借调查谋划自己的事情、以免被利用造成灾难。
  - 秘偶感官中的特莉丝：周围**有数不清的、看不见的丝线在飘动在张扬，而她本人脸色苍白、衣裙深黑地坐于中间，就像一只趴在丝网核心位置的蜘蛛，可又充满了让人怜惜让人靠近的诱惑力**。
  - 她认识塞尼奥尔（“我曾经在海上度过了一段难忘的岁月”）。
  - 关于埃德萨克王子之死：特莉丝猛地抬头、脸上浮现几分怒意：“**自杀和自杀是不同的，有人是自愿，有人是被逼迫。**”并称“**就是他（威廉·赛克斯）逼迫埃德萨克自杀的，用的是能泯灭灵性的子弹**，不过，他也是听从别人的吩咐，嘿，他为了得到最后的欢愉，全部都交代了，呵呵，我依然没让他真正地碰我，我还给他看了我以前的照片，他死得很痛苦很绝望……”
    - 克莱恩的吐槽与观察：特莉丝的心灵还是和以前一样扭曲；到了“欢愉”阶段的魔女自带魅惑（一个表情一个动作都能让人受到吸引），不过她已很好地收敛了这些、只在必要时使用；并猜测“她晋升了？或者因为有了爱情？”
  - **幕后指使者**：特莉丝给出“**斯特福德子爵。王室的宫廷侍卫长。**”

## 与特莉丝的合作框架（第43章）

- 克莱恩的判断：“**从这个职位看，贝克兰德大雾霾事件背后确实有王室某个派系的影子**，至于是谁，有待调查。”
- 特莉丝的合作逻辑（她自述）：“因为这对我来说，是一件好事，看得出来，你和你代表的势力对王室、对幕后那些家伙的真正图谋很感兴趣，**如果能通过提供一些有效的线索，让你们与他们发生冲突，让真正的阴谋家浮出水面，我非常乐意，这有助于我复仇，而且是极大的帮助。**”
  - 克莱恩的解读：这也意味着他能利用她、驱使她调查这件事、钓出藏在幕后的真正黑手，从而让自身势力在掌握有效情报前始终藏在安全隐蔽的地方；她这番话就是在**诱导他进行有限度的合作、并自愿成为揭开真相的“排雷兵”**，以此表明自身被利用的价值——**她害怕他最终决定杀她**。
- 关于“斯特福德子爵”的玩笑：特莉丝说“我只希望他喜欢的不是男人”；克莱恩腹诽“如果你已经有了序列5，可以考虑换到‘猎人’途径的序列4‘**铁血骑士**’……还有，你忘记过去的自己了吗？为什么越来越习惯应用‘欢愉魔女’的能力来对付男性”；塞尼奥尔则答“这不是问题，你可以给他看你以前的照片”——特莉丝因此羞恼（“深埋于心底的羞耻被人活生生挖了出来，暴露于阳光底下”），随后收敛情绪说“不愧是‘血之上将’，对魔女途径果然有着足够深刻的了解”。
  - 克莱恩的反思：她之前并不确定（他以为魔女教派和玫瑰学派有过合作，所以她相信“血之上将”知道“刺客”途径的秘密，这才开了那句玩笑）；“不管怎么样，嘲讽别人性别都是不太好的……嗯，这倒是挺符合‘血之上将’的人设……**秘偶大师的守则之一是‘记住，每一个人偶都有它自己的设定’**”。
- **联络方式**：特莉丝抓下一绺黑发、用幽蓝冰片切下，再以漆黑无声的火焰烧成灰烬；灰烬没有被阴冷的风吹起，而是向内收缩、汇聚成一团糨糊般的黑色事物。
  - “**将它们均匀涂抹在镜子上，我就知道你要找我了，我后续会利用那面镜子和你进行交流**……这大概能用五次，足够了。”
  - 克莱恩提出的反向联络：这条下水道藏着不少秘密、他经常过来，可**把需要的帮助用文字方式留在这里**；若事情紧急来不及，可先联络瓦尔特（“刚才那位”）来这里留言。特莉丝缓慢点头同意。
  - 他决定暂不暴露信使（“等特莉丝真的发现了再更改联络方式也不迟”），因为“**这不是一个值得信任的人**……她为埃德萨克王子复仇，或许确实有真情实意，但多半还包含着别的目的，比如，也为自己复仇”。
- **重要发现（蓝宝石戒指）**：那枚堪比“0”级封印物的**蓝宝石戒指不见了**——克莱恩推断她当初能逃离埃德萨克王子的红蔷薇庄园、摆脱因斯·赞格威尔和“0-08”的控制，也付出了不小的代价；并追问“**原初魔女**在她身上留下的印记也随之不见了？”
  - 询问“你将灵魂卖给了哪位邪神？”→ 特莉丝答“**原初魔女**”。
  - 克莱恩的震动：“你当初不是想摆脱那种古怪的状态吗？不是不想越来越不像自己吗？怎么走起回头路了？你难道不知道，**她们给你改名特莉丝奇克，就有让你成为‘原初魔女’容器的用意**？不，她还真不知道，她甚至不明白‘奇克’这个称号的意义……**用尽全力逃出宿命，却是更进一步地融入宿命**……”
  - 特莉丝的解释：“因为这对我来说是问题，不是秘密。**多一个人知道，也许就会多一份解决问题的希望**，哪怕这希望非常渺茫，但也比没有好。”
- **克莱恩的提醒**：“当你靠近斯特福德子爵、靠近藏在幕后的那些家伙时，**注意自身是否经常有遇到巧合的事情**”——因为调查贝克兰德大雾霾事件越深入，越有可能被**因斯·赞格威尔和“0-08”**注意到；特莉丝由此回想起在红蔷薇庄园时遭遇的那些巧合，猛然抬头时塞尼奥尔已消失不见。

## 行动准备：装病与阿罗德斯（第44章）

- 瓦尔特次日表现如常（完全看不出昨晚去过下水道）；克莱恩以“怀念家乡”为由让厨师次日准备**迪西馅饼**。
- 礼仪课重点转为**下午茶礼仪**（因他要去莉亚娜夫人处）；但管家汇报**马赫特议员家的下午茶活动取消，因为莉亚娜夫人的女儿海柔尔小姐生病了**，她很抱歉、希望下周再邀请。
- **克莱恩的推断（重要）**：“海柔尔明显还未见过魔药带来的失控变化，精神状态还算健康，以至于表现得很优越、没有畏惧感，即使有受到惊吓，也不至于出现心理上的疾病……**疾病……魔女途径的序列5能让周围的人染上疾病……**”
  - → “昨晚，特莉丝察觉到有陌生人进入下水道后，**悄然散布了疾病**？而‘怨魂’状态的塞尼奥尔是不会感染的，所以我没有发现……这样问题不大，海柔尔并未在疾病环境里待多久，只是因为受到惊吓才没有很快恢复……”
  - → 结论：“**看来特莉丝真的晋升序列5了。**”
- 圣赛缪尔教堂：他在此遇见**伦纳德·米切尔与戴莉**（伦纳德精神紧绷、身体微不可见地僵硬；克莱恩含笑点头、神情友善；伦纳德挤出少许笑容、让开道路）。
  - 他趁机看清后面那位是**穿通灵者黑袍的戴莉**（依旧涂蓝色眼影和腮红、妖异美丽）；**戴莉瞄了眼经过的中年绅士、神情突然恍惚了一下**。克莱恩猜测“我只是模仿了下队长眼睛那种幽邃的感觉，就连颜色都不一样，戴莉女士也能感觉到熟悉？女人的直觉真可怕”。
  - 他的回忆（人物关系）：很早之前在他的直男认知里，**戴莉女士就是暗恋着队长的**，否则不会承担风险赶到廷根、让克莱恩找机会将扮演法教给邓恩·史密斯；至于队长的态度他没法确定（那段时间邓恩经常分不清现实与梦境、记忆问题相当突出）；但**队长确实常常提起戴莉，总是拿她举例来教育他们，对她用了多少年晋升、有什么样的天赋熟悉得仿佛能倒背出来**——这和他当时记忆不好的状况有点矛盾；队长说起这些时偶尔会加上“自己从‘午夜诗人’到‘梦魇’用了足足九年”的陈述；克莱恩因此猜测“**他面对戴莉女士时，内心是不是有点自卑**”。
- **红手套的新任务**（索斯特传达）：“我们这次的任务是根据之前‘**黑骷髅党**’总部爆炸事件里发现的各种线索，**找出潜藏在贝克兰德的灵教团正式成员**。戴莉女士是‘收尸人’途径的非凡者，对灵教团有相当深厚的了解，所以**圣安东尼阁下让她来协助我们**。”
- **刺杀X先生的准备（重要）**：克莱恩以“世界”格尔曼·斯帕罗向“魔术师”转达要求：
  1. 周五晚上前，于**东区订一个旅馆房间**，最好远离X先生召集聚会的地方；
  2. **提前将那枚石头和魔法书给他**，他需要做一定的准备；
  3. 周五晚上她必须**阻止参加X先生聚会的那位朋友**，并将对方**乔装改扮后的外形特点**呈现给他；
  4. 若有别的事项会及时告知。
- 他的行动思路：
  - 计划利用“无面人”的能力**伪装成对方参加X先生聚会的那位朋友**，掌握暗号直接进入，再针对不同情况采用不同预案。
  - **“秘偶大师”守则**（他总结的）：“应该有一条是**尽量藏在幕后，隐蔽地导演一出戏剧**”；除非实在没有别的办法，否则“秘偶大师”应避免与别人正面战斗。
  - 难点：X先生的聚会在**8点**，那时道恩·唐泰斯显然还没睡、无法长时间摆脱管家与仆人们的注视秘密前往东区（反过来也能制造不在场证明，但问题在于用什么办法瞒过这栋房屋内的所有人）；若有“无面人”同伙就好了（“正义”小姐那条项链能办到，可她不在贝克兰德）。
  - 他也想过直接自己召唤自己、自己响应自己，用侠盗“黑皇帝”这个身份行动，但那样就会**丧失让肉体变化模样的能力、难以附身别人**，无法伪装成佛尔思那位朋友。
  - **最终方案：装病**——从明天开始“生病”、每天吃很少东西、8点不到就睡觉，这样就不会有管家和仆人来打扰；若这边有紧急事情、瓦尔特他们来敲门，就把**幻觉固定在镜子上让它看起来像道恩·唐泰斯，再让“魔镜”阿罗德斯远程操纵问答**。
- **与阿罗德斯的约定**：他画出糅合隐秘与窥视符号的混合图案召唤阿罗德斯。
  - 问：“我打算清除极光会的神使X先生，你有什么建议？”→ 答：“**您最好将计划放在周四之后。**”（符合他自己的占卜：周四及今晚，X先生附近可能有“命运天使”乌洛琉斯或极光会的圣者之一。）
  - 请他帮忙：周五晚上用一面镜子做幻术道具、将它变成他这个身份的样子；若有紧急事情由他操纵镜子进行问答、不让人发现异常。阿罗德斯激动应下，并称能**模拟任何声音**（“虽然这无法维持太久，不符合我的习惯，但也足够应付这里所有人”）；克莱恩警告“应付的时候，掩饰好问答游戏的本质，不要被人发现”（他担心阿罗德斯向管家与贴身男仆提出让人羞恼的问题——如同当初把达尼兹玩到快崩溃）。
