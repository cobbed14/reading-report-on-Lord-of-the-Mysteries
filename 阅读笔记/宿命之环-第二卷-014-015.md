# 《宿命之环》第二卷《逐光者》第14—15章 考据

批次区间：[439433, 446341)，下一位置为第十六章《挣扎》。分两次提取（卷二14、15），正文完整返回，无截断。**本批含奥斯塔的来历与聚会召集人“K先生”、“蒙苏里鬼魂”传说的完整样貌与一次疑似遭遇，以及卢米安向那位伟大存在祈求自保。**

> **源文件用字提示（已核实）**：疯子的房间在前文与后文均作“**310房间**”（全文共 5 处），但在本章（第十五章）内有一处误作“**10号房间**”（字符位置 442859）。属同一房间的异写；引用时以“310 房间”为准。

## 一、召集人：奥斯塔的来历与“K先生”（第十四章，极重要）

- **【奥斯塔的“诈骗心得”（人物素材，极重要）】**：
  - “‘**大部分时候其实不算骗，我作为一个“秘祈人”，真正意义上的非凡者，用自身灵性给他们做占卜，根本称不上欺骗啊。我占卜的结果可比神秘学俱乐部里大部分人准确多了！**’”
  - **【他的要诀（极重要）】**：“‘**重点是最开始不要把话说得太清楚太绝对，之后才能指责对方理解错了。**’”
  - **他的自我检讨（极重要）**：“‘**正确的做法应该是告诉你我有办法，但非常难实现，在你恳求很多次后，才勉强收下你的钱，并说不保证成功……**’”
  - 卢米安的评价（人物素材，极重要）：“‘**你真的选错了途径。**’”
- **【他的来历（极重要，一段极完整的都市底层侧写）】**：
  - **特里尔的“追梦者”（极重要）**：“‘**每个人都是带着希望来到特里尔的，那些画家做梦都想让自己的作品被在世艺术家作品展览会选中，但绝大部分都是失败的落选者，每年都有人受不了这种打击疯掉或是自杀。**’”
  - “‘**住在廉价公寓的贫困作家们每一个都想重复奥萝尔、梅尼埃这些畅销者的成名神话，可最终只能把作品卖给那些小报纸，还要忍受“庸俗”“低劣”“桥段重复”等不好的评价，他们之中甚至有不少人沦落到给地下书商写色情小说，随时可能被警探带走。**’”
  - **【他自己（极重要）】**：“‘**十几年前，我从西第利斯省来到特里尔，带着发财的渴望，我睡过那种一下雨就会漏的阁楼，爬过脚手架，进过工厂，走私过地下书籍，当过卖汽水的小贩**’”“‘**但我一年比一年清楚，我永远都没法成为有钱人，不可能拥有自己的房屋，不可能悠闲地在家里一边看报纸一边用早餐**’”
  - **【他为何接触神秘学（极重要）】**：“‘**后来，我接触到了《通灵》《奥义》这些神秘学方面的杂志，呵呵，可能是还有幻想，觉得能一夜之间获得强大的超凡力量……我开始频繁地参加同好者之间的聚会，嗯，那些杂志上会刊登相应的信息。**’”
  - “‘**今年年初，我在同好会里认识的一个朋友突然找到我，问我要不要参加涉及真正非凡力量的聚会，我没法拒绝**’”
- **【聚会召集人：K 先生（极重要）】**：
  - “‘**召集人自称“K先生”，每次都戴着很大的兜帽，几乎将整张脸都遮住。**’”
  - **【奥斯塔对他的感应（极重要）】**：“‘**我没有见过。不过，我成为“秘祈人”后，再遇到他时，会有一种面对阴影面对地底深处那些黑暗的感觉，我想，他应该很强。**’”
  - **一段极妙的对话（人物素材，极重要）**：
    - 卢米安问“**你面对我，有没有特别的感受？**”——“‘**没有，但你有种危险的气质，比布里涅尔男爵更让我害怕。**’”
    - **卢米安的回应（极重要）**：“‘**卢米安低头看了眼自己的左胸，笑着说道：“挺好的。”**’”
- **【“蒙苏里鬼魂”传说的完整版本（极重要）】**：
  - “‘**传说在地底这片又黑暗又广阔的空间里，有个恶灵在不断地徘徊，它总是孤独地走着，似乎永远都抵达不了目的地，谁要是碰到了这鬼魂，要么当场失去生命，要么在当年，连同他的直系亲属一起，神秘死掉。**’”
  - **【一个极重要的补充（极重要）】**：“‘**到目前为止，自称遇到过蒙苏里鬼魂的人都疯了，也都在一年内就死了，我听说两大教会组织过强者到地底寻找那恶灵，但没有成功。**’”
- **【本章最戏剧性的一段：他疑似遭遇了蒙苏里鬼魂（极重要）】**：
  - **与守门老者的对话（极重要）**：
    - **他被拦下（极重要）**：“‘**一道人影从巨石拱门后转了出来，沉声喝道：“站住！”那人影套着蓝色的马甲，穿着黄色的长裤，是个头发花白皱纹不少的老者。**’”
    - “‘**你得先到上面买票，再带一根白色的蜡烛过来。**’”
    - **一个极有趣的旁证（极重要）**：“‘**你不会是纪念堂区的大学生吧？那帮混蛋小子总是编各种谎言混进墓穴，在藏骨堂里唱歌，跳舞，开宴会！进去吧，记得和那些家伙一样带上点燃的白色蜡烛，这是我唯一的要求！**’”
      - **卢米安的感慨（人物素材，极重要）**：“‘**卢米安以前还担心自己如果能考上大学，行事风格会和同学们差异过大，现在看来，这完全是多余的忧虑。那帮学生比他还要疯！**’”
  - **【黑影（极重要）】**：“‘**他眼角余光突然瞄到了一道黑影。那黑影略微弓着背，缓慢地行走在左侧那排石柱后面。卢米安一眼望去，有种它并非实体近乎虚幻的感觉。**’”“‘**下意识间，卢米安举起了电石灯，让蓝中泛黄的光芒投了过去。那黑影不见了，就像从未出现过一样。**’”
  - **【他的反应（人物素材，本批最精彩的一笔）】**：“‘**“该不会是蒙苏里鬼魂吧，我碰到蒙苏里鬼魂了？”他的瞳孔随之放大，表情变得异常凝重。几秒后，卢米安笑了起来，笑得差点直不起腰，笑得险些流下眼泪：“哈哈，来，尽管来！我倒要看看你怎么让我死掉所有直系亲属，怎么让我也神秘死亡！”**’”

## 二、自保之法：疯子证词与两次祈祷（第十五章，极重要）

- **【他从疯子处问出的完整证词（极重要）】**：
  - **黑影的形象（极重要）**：“‘**一道黑影，像个孤独的老头，背有点驼，走得很慢。我注意到它之后，它就消失在了黑暗里**’”
  - **【他家人的死法（极重要）】**：“‘**我孩子生了重病，死在了医院，我们刚让他接受净化，葬到了地下墓穴，我妻子，我妻子就崩溃了，自己吊死在了房间里。**’”“‘**直到这个时候，我才想起蒙苏里鬼魂的传说，带着父母去了教堂，请那里的神甫保护我们。**’”
  - **【教会的介入（极重要）】**：“‘**教会很重视，派了整整三名神职人员住到我家里，那段时间，什么事情都没有发生，我以为噩梦已经过去。**’”“‘**过了新年，那几名神职人员撤离了，没多久，我父亲勒死了我的母亲，用家里的餐刀结束了自己的生命**’”
  - **他自己（极重要）**：“‘**我除了经常感觉黑暗里有什么东西在看着我，没别的遭遇，要不然，我也不可能活到现在。**’”
  - **【一个极重要的矛盾（极重要）】**：“‘**不是说蒙苏里鬼魂会在当年杀死遇到他的人吗？这已经到了新一年。**’”——“‘**我不知道为什么会这样，我当时以为噩梦已经结束了，要不然那三名神职人员也不会离开……**’”
    - **卢米安的新推断（极重要）**：“‘**没有结束时间的诅咒，除非目标全部死亡？**’”
  - **一个细节（极重要）**：“‘**再后来，我很多事情都不记得了，偶尔醒来才发现自己不知什么时候搬到了这里……**’”
- **【本章的一个极重的人物背景揭示（极重要）】**：
  - “‘**他在梦境里对莱恩等人说自己原本叫什么已经忘记，是骗他们的，他只是单纯地不想再提及，不想再回忆。**’”
  - **【他的家世（极重要）】**：“‘**幼年时期的他家庭情况还算不错，但那个被他叫做父亲的男人是个花花公子，后来还成了赌徒。他的母亲被气到病死，他的爷爷被弄到破产，带着他住到了贫民区，没几年也过世了。**’”
  - **【改名的原因（极重要）】**：“‘**所以，被奥萝尔收养后，他主动问能不能跟着她姓，换一个全新的名字。**’”
  - **【他对生父的态度（极重要）】**：“‘**卢米安不知道那个单纯只是贡献了体液的家伙现在是死是活，如果已经死了，那毫无疑问是件好事，要是还没有，他希望蒙苏里鬼魂加把力。**’”
- **【他对自身处境的清醒（极重要）】**：“‘**卢米安可不敢仗着体内有邪神污染，身上有伟大存在封印就认为蒙苏里鬼魂不会对自己做什么。只要不附到他身上，对方什么都能做！**’”“‘**按照“魔术师”女士的说法，卢米安相信很多非凡者和怪物都能轻松杀死自己，只是之后得面对散逸出来的污染。**’”
- **【一个极妙的“方法论”（极重要，人物素材）】**：“‘**奥萝尔以前经常说，对弱小的人或者未成年而言，最强的能力是“找家长”……**’”“‘**虽然那位以“魔术师”为代号的女士不是他的家长，但就目前的情况而言，绝对称得上他的上司，而遇到困难，向上司求助，是合情合理的一件事情！**’”
- **【一个极重要的组织推论（极重要）】**：
  - “‘**这是卢米安通过那位女士以塔罗牌的“魔术师”为代号，而自己拿到了塔罗牌的“权杖七”推测出来的。**’”
  - **【他的完整推测（极重要）】**：“‘**他怀疑那位“魔术师”女士很可能属于一个以塔罗牌为象征，信仰着那位伟大存在的隐秘组织，其中，大阿卡那牌是正式成员，每一位都异常强大，小阿卡那牌是外围成员，承担着不同的任务。**’”
  - 他在信末特意落款（极重要）：“‘**权杖七**’”——“**以提醒对方不要忘记自己属于他们那个神秘组织的外围成员**”
- **【“魔术师”信使的第二次登场（极重要）】**：
  - **它直接出现（极重要）**：“‘**而这一次，那个小臂高，形似玩偶，穿着淡金色小裙子的信使直接出现在了火焰顶端，漂浮在那里。**’”
  - **它的评价（人物素材，极重要）**：“‘**比上次好多了。**’”
  - **一段极可爱的对话（极重要）**：“‘**事实上，我也不喜欢那些臭虫。**’”——“‘**是吧？没有任何生物会喜欢那些虫子！**’”“‘**卢米安看得出来，它的态度还算满意，似乎是因为“双方”讨厌同样的东西。**’”
    - 卢米安的感慨：“‘**有信使真是方便啊……**’”
- **【他自行想出的备选方案（极重要）】**：
  - “‘**“猎人”加“挑衅者”都没有处理诅咒的能力，如果真是诅咒的话……“舞蹈家”也不行，除非跳完祭舞后，真的向那位隐秘存在祈求，可这和自杀有什么区别？**’”
  - **【转向那位伟大存在（极重要）】**：“‘**向那位隐秘存在祈求不行，我可以找那位伟大存在啊！我身上有祂的封印，窃取“恩赐”的时候还得到过祂的允许，也不怕再向祂祈求一次！嗯，祈求祂帮我消除身上的诅咒。**’”
  - **他的布置（极重要）**：“‘**因为“魔术师”女士未特意提过那位伟大存在所在领域的材料，所以卢米安相信用什么都应该不影响最终的结果，只要不涉及别的神灵。他还是摆上了柑橘和薰衣草制成的橙黄色蜡烛，两根代表神灵，一根代表自己。**’”
  - **【本章末尾的祈祷（极重要）】**：“‘**用赫密斯语念道：“不属于这个时代的愚者，灰雾之上的神秘主宰，执掌好运的黄黑之王……”**’”

## 三、待核对／未解线索（不做断言）

- **那位伟大存在是否会回应他的祈祷**。
- **“魔术师”女士为何未回信**。
- **蒙苏里鬼魂**是诅咒还是某种存在（**两大教会曾组织强者搜寻而未成功**）。
- 他推断的**塔罗牌组织**（**大阿卡那＝正式成员、小阿卡那＝外围成员**）是否成立。
- **K 先生**的真实身份与序列。

## 四、整合包可用要点小结

- **【组织推论（极重要）】**：卢米安由**“魔术师”（大阿卡那）与自己的“权杖七”（小阿卡那）**推断——**那位女士很可能属于一个以塔罗牌为象征、信仰那位伟大存在的隐秘组织**；**大阿卡那牌为正式成员（每一位都异常强大），小阿卡那牌为外围成员（承担不同任务）**；他**以“权杖七”落款**表明外围身份。
- **【一个重要人物：K 先生（极重要）】**：**神秘学聚会的召集人，自称“K先生”，每次都戴很大的兜帽遮住整张脸**；**奥斯塔成为“秘祈人”后面对他会有“面对阴影、面对地底深处那些黑暗”的感觉**——**疑为强者**。
- **【“蒙苏里鬼魂”（极重要）】**：**地底徘徊的恶灵，孤独行走、似永远到不了目的地**；**见者或当场丧命，或在当年连同直系亲属神秘死去**；**自称遇到它的人都疯了并在一年内死去**；**两大教会曾组织强者到地底搜寻而未成功**。**疯子的证词给出了一个关键例外——那诅咒似无结束时间，须目标全部死亡方止**（他孩子在医院病故、妻子自缢、父亲勒死母亲后自尽，期间教会派三名神职人员驻守时一切平静，撤离后即出事）。
- **【他的自保思路（极重要）】**：**“猎人”“挑衅者”“舞蹈家”皆无处理诅咒之能**（向那位隐秘存在祈求等同自杀），**故转而向那位伟大存在（他身上有其封印、窃取恩赐时也曾获其允许）祈求**；**以柑橘与薰衣草制成的橙黄色蜡烛布祭坛（两根代表神灵、一根代表自己）**，以**赫密斯语**诵念其尊名。
- **【“魔术师”信使的习性（极重要）】**：**它在意环境洁净**（**第二次见面即评“比上次好多了”**），且**与卢米安因“双方讨厌同样的东西”而关系趋近**。
- **【他的身世（极重要）】**：**原家庭尚可，但父亲是花花公子兼赌徒，母亲被气病死、祖父破产后带他住进贫民区并很快过世**；**被奥萝尔收养后他主动请求改随其姓、换新名字**；**他对生父毫无感情**。**这也解释了梦境中他说“忘记原名”实为不愿再提**。
- **【几处世界细节】**：**纪念堂区的大学生常编谎混进地下墓穴、在藏骨堂唱歌跳舞开宴会**；**神秘学杂志《通灵》《奥义》会刊登同好聚会信息**；**在世艺术家作品展览会**是画家们的梦想门槛。
