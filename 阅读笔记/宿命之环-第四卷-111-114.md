## 一、卢加诺的过去（第 111 章，重要伏笔）

- 【事实】他当赏金猎人时“会借助达列日山脉一些隐秘的山口来回走私点东西赚钱，甚至帮某些通缉犯潜逃出国”。
- 【事实】**坦科**：被他帮助潜逃的通缉犯之一，**从费内波特逃到因蒂斯**；后来在“山岭深处找了个谷地，自己弄了一片田，种了粮食和蔬菜，养了些牲畜，几乎不和其他人来往”；卢加诺定期带盐、糖、布料到访，**报酬是坦科教他神秘学知识**。
- 【事实·其精神状态】“有时候很沉默，脾气又臭又硬，像块石头，**仿佛在忏悔着什么**”；“有时候又很开朗健谈”；偶尔说“**他背离了母亲的教导，坠入了恶的深渊**，以至于越来越不像自己，越来越痛苦”；偶尔又说“**教会在骗人，真正的母亲早已远离了现世**”。
- 【事实·其死亡】去年深秋，坦科说自己“再也无法忍受一身堕落和罪恶”、快对抗不了“内心深处潜藏的那个魔鬼”，想在被彻底控制前自尽，并托卢加诺**把遗物送到加亚省首府托莱尔，交给“大地母神”教会的神职人员，最好是神眷者**。
  - 次日清晨，他**死在刚收获完谷物的田里**——“他的身上，**长了一粒又一粒金黄的麦穗**，他，**还长了好几个女性生殖器官**”。
- 【事实·卢加诺的选择】他在坦科身旁发现“**一团像是谷物种子的金黄色东西，但足有半个拳头大**”，怀疑是坦科非凡力量的来源；**最终没有遵守约定，把那团东西吃掉了**——因此成为“耕种者”。
- 【推测·卢米安】“那个坦科明显是出了问题、很可能接触过邪神信仰，**他遗留的非凡特性大概率存在一定的污染，这样也敢直接吃**……难怪会遇上神降学派的人、会听见婴儿的哭声、会那么容易就因为接触到埃尼奥这类病人遭受污染和影响”。
- 【事实·“魔术师”的回信（相关段落）】
  1. “以你和神子的牵扯、以你身上封印着的邪神天使，**遇到‘神降学派’的成员不算是巧合**。”
  2. “但你的翻译兼向导**既是‘耕种者’途径的非凡者，又有别的一点问题**，遇到‘伟大母亲’相关的事情也很正常”——“至于是什么问题，你自己思考和询问，我就不直接告诉你答案了，**‘阴谋家’就得多用自己的头脑**……”
  3. 关于卢米安上次那个“阿蒙为何绕大圈子”的疑问：“**应该是阿蒙和祂背后那位提前做了什么，才导致那位天尊忽略了相关问题**”“总之，这看起来对你对我们都有利，**当前可以装作没看见未想到，不去探究**”。
  4. “婴儿哭声纠缠的问题，**可以找‘大地母神’教会的神职人员解决一下**。”

## 二、改信与“欢迎回家”（第 112 章）

- 【事实】埃尼奥已好转——以太体各色恢复到“较为正常”的状态，只是偏黯淡稀薄。
  - 【事实·蒙塞拉特的解释】内脏可以移植（只要保留一定活性）；**普林皮诺一直以非凡能力保持着那些器官的活性，且用的都是埃尼奥自身的器官，无需考虑排异**；而“埃尼奥本人还活着、还靠神秘学力量维持着一定的生命力”也是关键。
- 【事实·污染的处理方式】蒙塞拉特称这是“**遭受相应污染后必然会出现的后遗症**”、会随时间消退，也可立刻清除；方法是**闭眼听布道、向大地母亲祷告**——“记住，是向大地母亲，而不是别的神灵”。
  - 【事实·体验】卢加诺“听见了母亲的呢喃，感受到了怀抱的温暖”，落泪、“身心都似乎得到了洗涤”；蒙塞拉特宣布“**大地母亲已经清除了你身上的污染**”。
- 【事实·改信】翌日卢加诺确认整夜无梦、无哭声；蒙塞拉特问“**你有没有兴趣追随大地母亲？**”——“**在母亲的眼里，没有异教徒，只有愿不愿意回家的孩子。**”
  - 【推测·卢加诺的真实动机】“真成了‘大地母神’的信徒，说不定还能从教会、从三大修会那里买到‘医师’后续的魔药配方和非凡材料……就算这件事情不行，相应的神秘学指导也肯定是有的。”
  - 【事实】他最终高举双手“赞美大地，赞美万物的母亲！”；蒙塞拉特张开双臂：“**欢迎回家。**”
- 【事实·布道中的尊称式描述】“你信仰的是**生命的源泉，万物的母亲，托起丰饶的大地，红月和繁衍的象征，以及一切的归宿，一切的起点**……”
- 【事实·章末】深夜卢加诺去祈祷室，从门缝看见**蒙塞拉特屈着双臂轻轻摇晃，仿佛正抱着一个新生的孩子——“可他的双臂之间，空无一物”**。

## 三、“大地母亲是‘伟大母亲’的一个侧面”（第 113 章，本批最重）

- 【事实】**那个空间的特征**：一片黑暗，其中“一丛丛偏黑的、结着饱满穗粒的杂草正静静摇晃”；蒙塞拉特怀抱无形婴儿现身，背后是“**近乎虚幻的、异常巨大的橡树**”，橡树靠近杂草的部位“**瘤体密布，形成了异常简陋的、颇为邪异的生命圣徽**”。
- 【事实·其教义核心（逐条）】
  1. “**我们都是母亲的孩子**”——并特意补充“‘**伟大母亲**’的孩子”；
  2. “**大地母亲是‘伟大母亲’的一个侧面，一个投影**，她以这个身份关注着**背叛之地**，关注着我们这些**离开了母亲怀抱的孩子**”；
  3. “这个世界上所有生物都是‘伟大母亲’的孩子——**有的是她孕育生下的，有的是这些神裔繁衍的后代，还有的是‘伟大母亲’的血肉直接变成的**；**我和你都是后面这种情况，我们和‘伟大母亲’的联系最为紧密！**”
  4. “**不用担心‘伟大母亲’的回归，哪有仇视自己孩子的母亲？**”——“在我们这个世界外，**还有很多的世界**，那些地方的生灵都在‘伟大母亲’的注视下茁壮成长着、不断繁衍后代，没听说哪个种群因此而毁灭，数量反倒越来越多”；
  5. “那是给了我们生命的‘伟大母亲’，**她真要拿回赐予我们的生命，也是她的权利，我们应该全力配合**。”
- 【事实·卢加诺的反抗与差点沦陷】他拔枪射击、拔手术刀，但都“戳中了空气”；被婴儿哭声夺去心神、走向橡树；**橡树上长出“湿润温热的蠕动肉瓣”，将他小半个身体包裹住往里拉扯**——这正是他先前感到的“母亲怀抱”。
  - 【事实·获救契机】危急时他听见“**自己母亲最爱唱的那首童谣**”，那声音**来自他身后**；母亲在背后一声声喊“**不要过去！不要往前！危险！**”→他打了个激灵，神采恢复，双手在肉瓣内用力一撑、挣脱。
- 【事实·其战斗力的自省】服食“耕种者”与“医师”两份魔药后，“除了力量很大、擅长使用农具和手术刀，**没有能直接应用于战斗的非凡能力**”——预测天气、分辨培育种子、治疗恶疾／创伤、缝合灵魂、给予生命、出色手术能力都不适合战斗；他此前主要靠赏金猎人的格斗与射击配合热兵器。
- 【事实·路德维希的“报警”】他主动找到卢米安：“**卢加诺遭遇了意外，你快去救他。**”——“他进了祈祷室后，我就没法感应到他的气息了。”
  - 【事实·“什么气息？”“**食物的气息。**”】
  - 【事实·其理由】“他要是死了，你又去做别的事情了，**谁帮我搜集食物**？”

## 四、救援与“大地母神”教会的裂缝（第 114 章）

- 【事实】三下敲门后是砰的巨响：木门后飞、走廊灯光照入、赤红火焰涌入→橡树与蒙塞拉特消失、杂草淡化、黑暗消退，卢加诺“回”到祈祷室。
- 【推测·卢米安对蒙塞拉特能力的评估】“和‘**彼岸世界**’类似的非凡能力，在不够独立于现实的情况下，融合了别的一些特质……**有点‘魔鬼巫师’布尔曼强行转途径后获得特殊能力的意思**”；并按路德维希的知识推测其“**躲到了木制品内**”。
- 【事实·“打量”的真意】**他先前用巨浪向船长与神父“打招呼”其实是震慑**——让潜在的危险分子顾忌“半神”的存在、躲得更深，等船靠岸交由教会处理。
- 【事实·关键发现】**他触摸生命圣徽上简笔婴儿的脸——那里的木头骤然腐朽、流出发黄的脓液**，“这看起来就像是被麦穗鲜花等簇拥着的婴儿早已腐烂，流下了血泪”。→【推测·卢米安】“‘大地母神’的教会问题很大啊。”
- 【事实·船长佩德罗的补述（重要设定）】蒙塞拉特是**神恩者**（“大地”途径的非凡者、最正统的神职人员），“**正常情况下，必须有一名神眷者辅助，才可以做弥撒、向信徒布道、引领他人加入教会，反过来则不用**”；而**这次上船只有他一个神恩者、没有神眷者跟随**——船长以为是祈海仪式导致桑塔港人手不足。
- 【推测·卢米安的重大推演（本批最重）】由上述规则想通了教会的双体系设计：
  1. “和站在‘学徒’、‘占卜家’和‘偷盗者’这三条途径顶端的‘**福生玄黄天尊**’一样，**‘伟大母亲’应该也是俯视着‘耕种者’、‘药师’和‘恶棍’等途径的存在**”；
  2. 所以“‘耕种者’和‘药师’这两条途径的非凡者作为**神恩者**，**也会受到‘伟大母亲’的影响，分不清楚获得的启示究竟来自‘大地母神’还是‘伟大母亲’**”；
  3. **必须通过不在这两条途径的“神眷者”确认才能肯定，同时神眷者们也在监控神恩者们的状态**；
  4. 结论：“这看似荒诞、浪费、没有道理的体系设计背后，有非常深刻非常严肃的原因。”
- 【事实·搜捕方案的评估】卢米安列了多个方案并逐条打分：①用船上扩音器辱骂“伟大母亲”挑衅（“在没法锁定目标的情况下，难以针对性地使用‘挑衅’能力”）；②烧掉船上所有木制品（“最后的选择”，因为很多货箱是木头的）；③找芙兰卡借“预言药水”（需新鲜尸体）或直接让她“魔镜占卜”；④吹“痛恨乐章”骨笛（“只是降低伤害不是免除影响”）；⑤问路德维希是否记住蒙塞拉特的气息（答“**没有直接的接触**”）；⑥**用“傲慢盔甲”对“大地”“黑夜”途径的憎恨来锁定目标**——先拿同为“大地”途径的卢加诺做实验。

## 六、整合包可用要点

- **“走私山口＋隐居谷地＋自杀式托付”**：一套极完整的“污染者”人物小传模板。
- **“吃下污染非凡特性”的代价**：一年后才显出后遗症（易被“伟大母亲”相关事件牵引）——把“贪便宜晋升”写成长期隐患。
- **“改信即治疗”**：以布道＋祷告清除污染，顺带完成传教——邪教招募的标准流程。
- **“大地是投影”的异端神学**：把正统信仰解释为更高存在的侧面/投影，是极有说服力的诡辩模板。
- **“肉瓣包裹＝母亲怀抱”**：把致命危险包装成温暖体验，比直接攻击更高级。
- **“敲门三下再踹门”**：把主角的礼貌与暴力并置，是极好的人物瞬间。
- **人物**：卢米安、卢加诺、路德维希、埃尼奥、蒙塞拉特（神父）、佩德罗（船长）、坦科（已故）、芙兰卡（提及）、“魔术师”（书信）。
- **地点**：费内波特南方海船（一等舱、祈祷室、船长室、甲板）、达列日山脉谷地（回忆）。
