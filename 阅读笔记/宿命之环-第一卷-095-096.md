# 《宿命之环》第一卷《梦魇》第95—96章 考据

批次区间：[335616, 342482)，下一位置为第九十七章《勇气》。分两次提取（095、096），正文完整返回，无截断。**本批是一整场狩猎“纵火家”的完整过程，也是卢米安迄今最凶险的一次战斗。**

## 一、“光明正大”的埋伏：一场层层设局的狩猎（第九十五章，极重要）

- **【他的装备与准备（极重要）】**：“‘**卢米安先是认真地给左手缠满一层层白色绑带，然后拿上“堕落水银”、铁黑色斧头、灰琥珀香水、饼干、奶酪、带着血水的羊排、做陷阱用的绳子和一袋凉下来的开水等物品**’”
- **【第一处陷阱（极重要）】**：
  - 地形（极重要）：“‘**那是位于路旁的一个深坑，正前方和左侧是垮塌的墙壁，右边堆叠着些许石头，后方通向一栋倒了大半的房屋。单纯只是从路上经过，很难发现这么一个天然陷阱**’”
  - 布置（极重要）：“‘**他蹲至深坑后面，扔了几根削尖的木头进去，接着盖上早编织好的绳网，填了些浮土在上面。**’”
  - **诱饵（极重要）**：“‘**卢米安将带来的渗着血水的两块羊排小心翼翼放到了绳网边缘，一半被地面支撑着，一半悬于深坑上空。**’”
- **【本节最精妙的设计：用香水与脚印做“警报器”（极重要）】**：
  - **他的自陈（极重要）**：“‘**和对付猎枪怪物时的策略一样，卢米安从来没奢望刚才的布置能够瞒过火焰怪物，可以让它遭受重创。这更多是针对目标超强嗅觉、观察能力和行为风格放的诱饵和“警报器”。**’”“‘**只有“猎人”才懂得怎么利用一个“猎人”的长处来对付它！**’”
  - **一个前提（极重要）**：“‘**当然，这一切的前提是目标主要依赖本能行事，残存的智慧仅限于战斗。**’”
  - **【香水的双重用途（极重要）】**：“‘**卢米安拿出灰琥珀香水，往墙头喷了一点。淡雅清甜的香味随之散逸……它们之中有一部分附着在了墙头和卢米安的身上。**’”“‘**紧接着，他往嘴巴里塞了块奶酪，咀嚼吞下，并确认身上残留的灰琥珀香水能掩盖住其余杂味。**’”
- **【火焰怪物的识破过程（极重要）】**：
  - “‘**它往前走了十几二十米后，鼻子突然抽了抽。它闻到了淡淡的血腥味。**’”
  - “‘**那两块还有血水残留的羊排映入了它的眼帘。这是很好的食物，但火焰怪物没有依循本能，直接过去吞食。**’”
  - **【关键（极重要）】**：“‘**很快，它嗅到风中有一点点不同于往常的香味。它瞬间就确定那两块血肉是陷阱，有“狩猎者”在附近埋伏。而这狩猎者和之前“隐身”观察它的那个似乎不一样，对“猎人”缺乏足够的认知，没提前处理好身上的味道。**’”
  - **它的诈术（极重要）**：“‘**它装作什么都没有发现，将距离又拉开了七八米。霍然之间，它转了过来……那颗火球嗖地飞向了卢米安原本“埋伏”的位置**’”
- **【第二段陷阱：让猎物自己“发信号弹”（极重要）】**：
  - “‘**刚才的爆炸声于他而言就是一枚信号弹，提醒他赶紧准备开启第二段陷阱的信号弹！让猎物自己发信号弹是卢米安和奥萝尔探讨后，冥思苦想出来的方案。**’”
  - 流程（极重要）：“‘**于不算宽敞的空地内跳起那时而癫狂时而扭曲的舞蹈**’→**呼唤来口器怪物**→‘**用右手拔出仪式银匕，于左腕处刺了个很小的口子**’→‘**用古赫密斯语喊道：“我！”**’→‘**迅速喊出后续命令**’→**附身成功**
  - **善后（极重要）**：“‘**卢米安强行压制住不适，用带来的白色绑带飞快绑好了那个小到快忽略不计的伤口。紧接着，他往嘴巴里塞了块奶酪，咀嚼吞下**’”
- **【本节最高的战术技巧：“退着走”回主路（极重要）】**：
  - “‘**然后，他死死闭上嘴巴，掉转过身体，踩着自己的脚印，顺着之前过来时的路线，一步步往后退去。靠着猎人的观察能力和“舞蹈家”夸张的柔韧性，卢米安每一步都踩准了自己留下的细微脚印，没留下多余的痕迹。**’”
  - “‘**没多久，他退到了道路中央，停在了那里。他就这样光明正大地停在了路上，只是保持着隐身状态。**’”
  - **【一个极重要的心理对抗（极重要）】**：“‘**卢米安又一次做起等待，通过不断浅度冥想又不断中止的方式收束着脑海内闪过的种种念头，不让自己去想接下来要袭击那个火焰怪物。这是以非常粗浅的方式干扰对方的危险预感。**’”
  - **出处（重要）**：“‘**而那个踩着自身脚印，以后退的方式返回道路中央埋伏的方法是奥萝尔曾经在某本小说里写过的。**’”
- **【致命一击（极重要）】**：
  - “‘**五米、三米、一米……他猛地扑往目标，并抬起左手握着的“堕落水银”，划向前方！**’”“‘**他没有再等待双方距离拉得更近，担心那样会触动猎物的危险预感，让它提前做出规避动作。**’”
  - **结果（极重要）**：“‘**刺啦一声，“堕落水银”锋利的刀身没入了火焰怪物的右胸。从“面条人”那里剥离的命运随之以虚幻的水银圆珠形式渗入了目标的体内。**’”
  - **命运之河再现（极重要）**：“‘**与此同时，那条由无数水银色复杂符号组成的河流又幽幽暗暗浮现了出来，其中少许命运正急速缩往银黑色的刀身。卢米安顾不得去挑选想要交换的命运，任由“堕落水银”自己发挥。**’”
- **一个意料外的重创（极重要）**：“‘**轰！怪物体表的火焰应激爆开。强烈的冲击波推走了卢米安和他的“堕落水银”，激射而出的一朵朵赤红火焰点燃了他的衣物，烧焦了他脸庞的皮肤。**’”
  - **【一个致命的连锁反应（极重要）】**：“‘**可是，身上火焰未被扑灭的情况下，他怎么都没法再次进入“隐身”状态。**’”

## 二、猎物与猎人：濒死与反杀（第九十六章，极重要）

- **【被追杀的绝境（极重要）】**：
  - “‘**火焰怪物一边追一边不断地扔出赤红的火球，炸得地上出现一个个坑洞，炸得卢米安被连续掀翻了几次。**’”
  - **他的坚持（极重要）**：“‘**忍耐着那种难以言喻的痛苦，一次次被爆炸产生的冲击波拍飞，又一次次站起，向着目的地时左时右时而弧形时而直线毫无规律地狂奔。**’”
- **【火鸦群的可怕（极重要）】**：
  - “‘**他看着在房屋内部翻滚前行的卢米安，于身周凝聚出了一只只赤色的火鸦。**’”
  - **【与火球的区别（极重要）】**：“‘**它们似乎能锁定目标，竟没有一个偏离，并且不断地根据卢米安的位置调整着自身的轨迹。**’”“‘**火鸦群落可不像随手捏的火球那么好闪避！**’”
  - **结果（极重要）**：“‘**另外一半火鸦全部命中了预定的目标，这栋摇摇欲坠的房屋彻底垮塌。石块、木头、粉尘和各种杂物交织着淹没了这里，将地下室埋得严严实实。**’”
- **【他的伤势（极重要）】**：“‘**但就算如此，他依旧已经多处烧伤，被炸得内脏都仿佛移位，如果未能得到及时的治疗，可能活不过一天。**’”
  - **一个实力对比（极重要）**：“‘**火焰怪物的攻击能力和爆发水平似乎比未使用“光之风暴”的莱恩还要强！**’”
- **【他的预案（极重要）】**：“‘**现在卢米安唯一庆幸的是，自己有做没法摆脱火焰怪物追踪，难以安心用祭舞祈祷的预案。他甚至有想过，自己弄塌这栋房屋，将地下室埋住，以争取时间，没想到火焰怪物帮他干了这件事情。**’”
- **【本批最关键的一幕：冥想完全激发荆棘符号（极重要）】**：
  - **他的做法（极重要）**：“‘**他将那瓶来自奥萝尔的灰琥珀香水拿了出来，拧开盖子，放到身前。**’”“‘**卢米安一直没有睁开眼睛，专注地坐于靠墙位置。他在冥想！**’”“‘**他脑海内早已勾勒出那轮赤红的太阳，并维持了好几秒。**’”
  - **代价（极重要）**：“‘**很快，卢米安听到了那仿佛从无穷远处传来又近在耳畔的恐怖声音。他脸上、手背上、脖子上，一根根青色的血管凸显了出来，飞快染上了赤红近火的颜色。与此同时，他皮肤表面渗透出了一个又一个银黑色的圆形斑点。**’”“‘**卢米安张开了嘴巴，但未能发出惨叫，整个人倒了下去，蜷缩了起来。**’”
  - **“堕落水银”的反应（极重要）**：“‘**那把“堕落水银”脱离了他的左掌，却什么也不敢做，不敢主动弹向未覆盖布料的脸庞和右手，尝试以接触的方式制造傀儡。它只是在那里颤抖，剧烈地颤抖。**’”
  - **效果（极重要）**：“‘**正要凝聚火球的怪物一下僵住。它也不可遏制地颤栗了起来。几秒之后，它狂奔而逃，放弃了狩猎。**’”
- **【一次几近失控的体验（极重要，本批最重要的心理描写）】**：
  - “‘**卢米安陷入了有无数火光闪烁的黑暗，脑海里充斥的是极致的痛苦和邪恶的意念。**’”
  - **【那个“阴影”（极重要）】**：“‘**这一刻，他有了不如死去的感受，并觉得心灵深处有什么事物在飞快滋长，一点点成形。那仿佛是由所有负面性格参杂某种意志组成的阴影，一旦拼凑成人形，就将彻底取代原主。**’”
  - **【唤醒他的东西（极重要）】**：“‘**看不到尽头只有绝望和痛苦的黑暗里，卢米安忽然闻到了一股香味：淡雅，清甜。那是奥萝尔的味道，时常会有的味道。**’”“‘**卢米安渐渐找回了一点思绪，耳畔似乎又听到了那轻扬舒缓的旋律。**’”“‘**我要活着！循环还没有解除！**’”
  - **他原本的打算（极重要）**：“‘**他原本只想模仿奥萝尔用熏香遏制失控迹象的行为，靠自然散发的香水味道唤醒自己，谁知那瓶液体竟一下倾泻了大半。**’”
- **【一个极重要的状态变化（极重要）】**：“‘**无需别人提醒，卢米安自己都能“闻”到身上有陌生的、让人毛骨悚然的味道。现在的他如果碰到瓦伦泰，都不需要刻意表现什么，直接就会被对方召唤圣光“净化”。**’”
- **【他的自我总结与警示（极重要）】**：
  - “‘**在状态不好的时候冥想，完全激发胸口的荆棘符号，简直是自杀行为……**’”
  - “‘**也就是我成为“猎人”后，没再这么做过，才能靠着灰琥珀的香味勉强压制住失控迹象，但凡之前多有几次，身体已出现些许异化，现在都变成怪物了……**’”
  - “‘**之后很长一段时间，除非想死，否则不能再这么做了……**’”
  - **他为何选择冥想而非祭舞（极重要）**：“‘**依靠冥想，他最多花费五六秒的工夫就能吓走火焰怪物，而那段神秘的祭舞需要三四十秒**’”
- **【交换的完成与最后一击（极重要）】**：
  - “‘**又过了好一阵，“堕落水银”自行颤动，告诉卢米安已交换完命运。**’”
  - **它的状态（极重要）**：“‘**他看见那个浑身焦黑冒着火焰的猎物。它正匍匐在一个石块围出的角落里，瑟瑟发抖。**’”
  - **【处决（极重要）】**：“‘**卢米安奔了过去，丢下“堕落水银”，双手握住斧头，用尽全身力气劈下。沉闷的声音里，未做反抗的火焰怪物脑袋和身体分离了。一股股鲜红的血液随之狂暴喷出，于地面化成一丛丛赤红的烈火。**’”
  - **章末（极重要）**：“‘**扑通，卢米安再也无法支撑，带着斧头跌坐于地。**’”

## 三、待核对／未解线索（不做断言）

- **交换走的“命运”**究竟是什么、对火焰怪物产生了何种作用（似即“被震慑后瑟瑟发抖、不反抗”）。
- 卢米安身上那股“**陌生的、让人毛骨悚然的味道**”会带来什么后果。
- **“猎人”魔药**是否如其预感般**完全消化**。
- 心灵深处那个“**阴影**”是否还会再来。
- 火焰怪物被“交换命运”后的具体表现机制。

## 四、整合包可用要点小结

- **【“猎人”式埋伏的完整方法论（极重要）】**：**以诱饵（带血水的羊排）＋香味（灰琥珀香水）设下“警报器”，而非指望一击奏效**；**用香水同时兼顾“诱敌”与“掩盖自身杂味”**；**以浅度冥想反复中止来干扰对方的危险预感**；**踩着自身脚印倒退回主路、光明正大地隐身埋伏**（**此法出自奥萝尔某本小说**）；**在五米至一米间果断出手，避免过近触动对方预感**。
- **【“纵火家”的完整能力（极重要）】**：**火球**（**炽白、可炸塌外墙**）、**火鸦群**（**能锁定目标、持续调整轨迹，极难闪避**）、**体表火焰应激爆开**（**会点燃并烧焦近身者**）；其**攻击与爆发水平“比未使用光之风暴的莱恩还要强”**；**被荆棘符号震慑后会直接放弃狩猎并狂奔而逃**。
- **【一个致命的连锁（极重要）】**：**身上带火时无法进入“隐身”状态**。
- **【完全激发荆棘符号的代价（极重要）】**：**冥想约五六秒即可完全激发**（远快于**需三四十秒的祭舞**），但**代价是近乎失控**——**青色血管凸显并染红、皮肤渗出银黑色圆形斑点、倒下蜷缩、无法惨叫**；**心灵深处会滋长一个“由所有负面性格参杂某种意志组成的阴影”，一旦拼凑成人形就将彻底取代原主**；**他靠灰琥珀香水的味道（＝奥萝尔的味道）唤醒自己**；**事后身上会带有“陌生的、让人毛骨悚然的味道”，足以被“太阳神官”直接视为需净化之物**；**结论：在状态不好时这样做近乎自杀，之后很长一段时间不可再为**。
- **【“堕落水银”的实战用法（极重要）】**：**刺入目标即可将储存的那段“命运”以虚幻水银圆珠形式注入对方体内**，随后**命运之河浮现、刀身自行抽取目标少许命运**（**持刀者不必亲自挑选**）；**交换完成前它只是颤抖、不敢妄动**；**交换完成后会自行颤动示警**。
- **【情感要点（重要）】**：**唤醒他的是“奥萝尔的味道”与那支母亲哄睡的旋律**——**“我要活着！循环还没有解除！”**
- **人物与地点**：梦境废墟（火焰怪物活动区、深坑天然陷阱、摇摇欲坠的房屋与地下室）；**火焰怪物（“纵火家”，已被斩首）**、口器怪物（附身）。
