# 《诡秘之主》第二部第232—234章考据

- 连续正文区间：`[1576810, 1587244)`；下一章为第二百三十五章《阿蒙可能的来历》。
- 【白银城环境／力量限制】城外探索必须持续保持烛光；黑暗超过约五秒就可能遭未知怪物袭击，曾有三名队员在八秒无光中无声消失。首席科林为“猎魔者”，能识别怪物弱点与材料并临场配制针对性药剂、圣膏、精油和印记，这只是其半神能力的一部分。
- 【东区线索】对愚者信徒的追查基本停歇；一批失业纺织女工及部分男工携失业家属或独自离开东区，目的地不明，选择对象显示可能存在组织性招募。该事件性质尚未确认。
- 【阿兹克线索】军情九处通过黑帮与情报贩子发布悬赏。金斗篷街廉价旅馆曾出现疑似阿兹克者，随后房间留下有限打斗痕迹；床下老鼠腹部及内脏腐烂、气场只剩黑绿。悬赏未撤，无法判断冲突结果。
- 【阿罗德斯能力】阿罗德斯主动侵入克莱恩梦境，以“忠实仆人”身份实时再现机械之心探索白崖镇陵墓，并允许快进或跳转；画面近似完全沉浸的现场记录，参与者不察觉克莱恩旁观。
- 【机械之心战法】贝克兰德大主教霍拉米克·海顿亲自带近十人探索。队伍先用净化炮弹、连射非凡枪械和神圣雨卷轴反复洗地，再前进搜集析出特性；成员还配备短效符咒饰品和非凡武器，体现其依赖工业火力、工匠资源和高消耗预案的组织风格。
- 【资源取得】陵墓中至少两只人皮幽影被消灭，析出如多面钻石、每面映照不同脸孔的特性，其中之一符合克莱恩交易条件。外围没有贵族陵墓常见的生平壁画，构成异常。
- 【封印物／阿蒙纹章】“幽灵画框”会让进入映照范围者灵体离体并永久成为画中肖像；原身体死后，即使解封，灵也会迅速消散。阿蒙纹章为十二格大小不等且半覆阴影的圆盘与指针，霍拉米克仅确认其为家徽；克莱恩将其解释为时间暗面、时间漏洞，属推测。
- 【墓室真相】先前探索者抵达主墓室后全部迅速衰老死亡。翻开倒扣画框后，停滞的一两千年时间恢复流动：蜡烛燃尽、尸体迅速腐烂。棺柩无尸，仅有绣着十二环虫子的金色软垫；画框肖像正是黑卷发、宽额、瘦脸、单片眼镜和尖顶帽的阿蒙。
- 【半神手段】现场的霍拉米克实为无灵体的炼成人偶，因此幽灵画框无效；时间侵蚀使其掉落锈齿轮、螺钉、蜡、骨与弹簧。真正霍拉米克未露面，说明机械教会用远程人偶承担墓室规则风险。
