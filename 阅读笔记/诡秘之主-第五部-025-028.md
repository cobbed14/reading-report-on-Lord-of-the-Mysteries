# 《诡秘之主》第五部《红祭司》第25—28章 考据

批次区间：[3407419, 3420991)，下一位置为第二十九章《熟悉的味道》。分两次提取（25—26、27—28），正文完整返回，无截断。

## 与“五海之王”纳斯特的会面（第25—26章，极重要）

- **克莱恩的“半神登场”（重要扮演心得）**：他化身为一只“**巨大又沉重的红头海雕**”飞临“黑皇帝号”，以人声说“我想拜见白枫伯爵”，随后俯冲降落、扭曲成人形——最终形象是“**戴高高礼帽，着宴会服装，脸上扣着羽毛面具的男子**”。
  - **关键细节**：他“**很薄，只有两根手指并起来那么宽**”！旁人的观感：“**有那么一瞬间，伯德·马斯坦似乎看见了行走的纸人，但对方又要比纸人厚一点！**”
  - **他对“诡法师”扮演的思考（重要）**：“他让自己的形象如此奇异属于半被动半主动的行为，**被动是因为红头海雕体型不够庞大**，分出部分制造衣物和面具后，哪怕没要内脏，也无法支撑起正常的人类体型，**主动在于，他开始摸索和尝试‘诡法师’的扮演，略微有了点想法：法师不是重点，重点在于以法师的办法表现出‘诡’这个单词！**”
- **“黑皇帝号”与纳斯特（重要设定）**：
  - 船的形象：“覆盖着纯粹黑色的巨大三桅帆船……**长近百米，悬有三面漆黑的帆布**。而甲板上，背靠船舱的位置，立着张**两三米高的斑驳石椅**，此时无人就座。”
  - **“黑皇帝号”的规矩（重要）**：“‘黑皇帝号’的主人有制定自己的律令，和其他海盗不同，**他和他的手下只抢劫财物，不做别的事情**！”
  - **二副“恐惧子爵”伯德·马斯坦**：“赏金早就超过万镑的大海盗，身着袖口领口花纹繁复的因蒂斯式衬衣，披着件暗红色的船长服”。
  - **纳斯特的称号（重要）**：“在‘黑皇帝号’上，‘五海之王’纳斯特**始终自称伯爵，这来自罗塞尔大帝的敕封**。当然，他也公开宣称，**迟早会建立属于海盗的国度，成为大公，亲王，乃至皇帝**。”“有正统**白枫伯爵**封号”。
- **克莱恩隐藏客轮与纳斯特的判断（重要）**：他用大型幻术让整艘客轮消失 → 伯德无法判断（“幽灵船？……幻术？……**这种层次的幻术，必然是半神级**”）→ 纳斯特只说“**绕过去。**”
  - 伯德的领会（重要）：“不管是不是幻术，**能让那么大一艘风帆与蒸汽混合动力的客轮在几百位海盗的注视下无声无息消失，绝非中低序列者能够办到**，那艘船上必然存在一位半神或者执掌着半神级封印物的强者！”“**为了一艘普通的客轮和未知的半神发生冲突，绝不是理智的行为**……对面半神只是隐藏客轮、未做任何反击，也说明**他不想和‘黑皇帝号’和‘五海之王’发生激烈冲突，所以仅是展现存在，做出威慑**。”
- **船长室（重要场景）**：“一根根烛台从高处倒垂往下，**左边41，右边40，数量各不相同**，它们的尽头，黑色平台耸起，簇拥着一张铁黑色的座椅。”
  - 纳斯特的形象：“此时的体型较为正常，一米九十出头……**戴着等比缩小的尖塔皇冠，身披黑底银边的长袍，脸庞线条坚硬，额头皱纹略显，下颌蓄着不长的黑色胡须，深黑的眼睛里流淌着暗红的光芒，让人不自觉就想低下脑袋**。”
  - 他的第一句话：“**我没见过你。‘诡法师’先生。**”（他已看穿克莱恩的途径）
- **对话要点（极重要）**：
  - 克莱恩的问题：“我想知道**你对罗塞尔大帝的印象**，所有人都知道，**你和你的父亲曾经见过祂，不止一次**。”
  - **纳斯特的“压迫力”（重要）**：他说“先坐”，“他话音未落，克莱恩已是感受到了一种强大的压迫力，**身不由己就要听从命令**”→“不过，**他来的只是秘偶，‘灵体之线’弹动间，薄如书本的人影迅速归于平稳**。”
  - **纳斯特对罗塞尔的评价（极重要）**：“我对罗塞尔大帝的印象很简单：**再没有人比祂更适合成为‘黑皇帝’。**”“他没解释‘黑皇帝’的具体含义和指向。”
    - 克莱恩的理解（重要）：“**虽然大帝在日记里表现出的是到了末年才下定决心往‘黑皇帝’途径转、并做了相应准备，但实际上，他很早就有一定的认知和倾向，不知不觉展现了出来，提前做了不少布局**……”
  - **贝尔纳黛也曾问过同样的问题**：纳斯特说“**曾经有人向我提过同样的问题**”→ 克莱恩猜“贝尔纳黛？”→“对。那个时候，**她还很年轻，不够成熟**，竟然问出了这么一个问题。**以罗塞尔大帝晚年的位格和层次，有什么秘密之事是交给我和我的父亲去做，比祂自己谋划、暗中行动，更加能保密的？**”
  - **克莱恩与罗塞尔的关系（重要情感落点）**：纳斯特问“你和罗塞尔大帝是什么关系？”→ 克莱恩“喟叹道：‘**算是老朋友吧。**’”
    - 他的内心：“毕竟那扇神秘光门之上，**两人对应的蚕茧就算不是左右‘铺’，也只隔了一个阻碍，挂在一起成百上千年**。这是现实层面的关系，而心理层面，**阅读了那么多大帝日记的克莱恩早不知不觉将对方视作真正的老乡**，与他有着同样的情感归宿和身份认同。”
  - **纳斯特观察到的“异常”（极重要线索）**：“**我和我的父亲几次面见祂的时候，祂都会站在靠西边的那扇落地窗前，凝望远方**，这有的发生在早晨，有的在中午，有的在傍晚，而那个房间，并不是只有那一排落地窗。”
    - 克莱恩的推断：“**西边……远方……迷雾海吗？**”→ 他“记起了大帝在日记里提过的那个神秘的原始岛屿，**记起了藏在迷雾海某处的深渊**”→ 纳斯特确认“这也是我的猜测”。
- **交易条件（重要）**：克莱恩问“不知道在哪方面的交易上，我能帮上忙？”→ 纳斯特：“**替我找到对应‘黑皇帝’的那张‘亵渎之牌’。**”
  - 克莱恩的回应（重要）：“**刚才的问题并不值一张‘亵渎之牌’，如果我能获得，我将用里面的内容逐项和你交易**，当然，我也许只能提供那张牌的线索。”
- **克莱恩的后续计划**：“比起只见过罗塞尔几面的‘五海之王’纳斯特，对这位大帝更为熟悉的是另外一位：‘**神秘女王**’贝尔纳黛！……**等回到贝克兰德，就让‘星之上将’联络‘神秘女王’，争取尽快和她再见一次面……**”

## 贝尔纳黛的回信与“工匠”身世（第26章末，重要）

- 嘉德丽雅收到回信，第一行内容：“**那确实是夏尔的后裔……**”
  - 她的判断：“那‘工匠’真是**罗塞尔大帝的直系后裔**啊……**不能再放任他与‘原始月亮’的信徒混在一起了，得把他带到‘未来号’上**……”
  - 她还想到“那个‘工匠’夏尔夫让人头疼的性格和品德，**觉得自己有管教的义务和责任**”。
- **弗兰克的新“实验助手”（重要伏笔）**：“之后会给你一个实验助手。”→ 弗兰克“露出纯粹的笑容：‘好的！’”
- 背景补充：“**没人能想到，这里是摩斯苦修会一个重要据点。**”“为躲避极光会可能的追查，‘星之上将’嘉德丽雅和她的舰队最近一段时间内都停留于这里！”

## 埃姆林请教神父（第27章）

- **乌特拉夫斯基神父的形象**：“身穿褐色教士服，头戴神职人员软帽，**宛若一座山峰的乌特拉夫斯基神父**”；“眉毛稀疏，眼眸浅蓝，几处皱纹明显”；“哪怕坐着，也如同一座小山”。
- **他的建议（重要人物刻画）**：区分“疏忽大意”与“故意欺骗”——“是，就**清除他**，否则，他必然会危害到别的人，危害到无辜者。**将他的生命终结，送回大地，重启轮回，是一种怜悯是一种净化……**”
  - 埃姆林的内心：“**神父说起杀人竟然比‘世界’更平静更自然更祥和！**”
  - 对“不想杀掉”的情况，神父的建议：“我并不提倡将问题诉诸暴力，**你可以将他带到这里来，让他听我布道，阅读圣典，体悟生命的可贵，感受母神的慈和，为所犯下的罪行劳作。**”
    - 埃姆林的反应：“**这不就是我所遭遇的一切吗……**”但认为“这个办法非常符合他的心意”，且“**没有上升到争斗的层面，不会引发血族内部的矛盾**”。
    - 难题：“**怎么把欧内斯·博雅尔带到丰收教堂？**”“从他在这里做义工开始，**贝克兰德所有血族都知道了要远离这片区域**，欧内斯·博雅尔也不例外，没可能被骗进来！”
    - 他的评估：“自己有**始祖莉莉丝赐予的指环**，而且能从‘魔术师’小姐那里**租赁到神奇强大的‘魔法书’**，要战胜欧内斯·博雅尔子爵不会太困难，**可想控制住对方，就不是那么容易的事情了**，毕竟那是一位血族子爵，相当于序列5的非凡者”。
  - 结论：“**打算下周塔罗会上颁布任务，寻求帮助。**”→“协作最好**分阶段进行，互相不见面**……”
- 神父的话：“**果实从播种到收获，是一个漫长的过程，需要耐心等待**，你看起来已经明白了这一点。”

## 奥黛丽与赫温·兰比斯：心灵世界的交锋（第27—28章，极重要）

- **出发前的“愚者”祝福（重要）**：她在基金会办公室祈祷后，马车上“眼前突然出现了一道绚烂的光柱。光柱里，**一个沐浴着金光背生十二对翅膀的天使徐徐降临，用火焰组成的羽翼将她层层包裹，又层层消散**”。
  - 她的判断：“**和以前的天使有点不一样呀……‘愚者’先生复苏更多的同时，祂的天使也更进一步恢复了？**”
  - 旁人毫无察觉（女仆安妮、大狗苏茜）。
- **会面（重要）**：起居室中坐着的正是“**王室顾问，赫温·兰比斯**”——“身穿衬衣、马甲、正装三件套和有条纹的蓝灰色长裤，打着暗红色的领结，**头发已然全白但依旧茂密，气质温和而儒雅**。他有一双**似乎藏满智慧和知识的蓝色眼睛**，除了抬头纹较重，其他地方基本没什么皱纹。”
  - 他主动起身行礼：“很高兴见到你，奥黛丽小姐。”
  - 他对心理炼金会的定位（重要）：“**我们心理炼金会是以研究心灵领域知识为目的建立的组织，我们更偏学术而非事务**，呵，既然是学术，**你完全可以当所谓的委员是大学里的教授**。”
  - 他还提及旧事：“我还记得两年前，**你甚至和我讨论起了伯曼的道德哲学和孔西索的实用主义**。”
- **“心灵世界”的完整结构（极重要设定）**：
  - “她看见了**蕴含着无数知识般的七道净光**，看见了难以描述形体的密密麻麻身影，看见它们弥漫于高处，覆盖着一切。**这是灵性的天空，这是灵界在心灵层面的映射！**”
  - “而灵性天空的下方，是**一片幽邃深黯的大海**，那里的每一滴水液都如同一道光影，都仿佛代表着一点意识一个烙印。”
  - “这片大海的近处，存在着**好几座岛屿**，其中一座属于奥黛丽自己。她清醒地认知到这是自己意识的象征表现，**露在海平面上的是自身能察觉的部分，被‘海水’淹没的则是平时无法把握无法探知的深层次意识**。”
  - **总结（重要）**：“这里是**心灵的世界，由灵性天空、集体潜意识海洋和个人意识岛屿组成的心灵世界**！”
- **赫温·兰比斯的入侵与“警戒”（极重要机制）**：
  - “岛屿下方，潜意识海洋较深之处，大片的灰蒙如潮水一样往两边分开，显露出一座不知什么时候出现的石制台阶。台阶之上，一道身影以闪现般的姿态飞快往上蹿升着”——正是赫温·兰比斯，“**这个兰比斯和坐在沙发上的相比，气质阴鸷，没有一点笑容**”，“就像一个**没经过允许也没有敲门的沉默访客**”。
  - 登岛后：“他**部分皮肤已覆盖着灰白的鳞片，眼眸呈金色，竖了起来**，不含一点感情。”
  - **奥黛丽的明悟（核心机制）**：“因为有‘愚者’先生那位天使给予的祝福，**赫温·兰比斯借助集体潜意识海洋隐秘侵入我心智体、心灵领域的行为触发了‘警戒’**……那股力量随之**分离出我最本质的自我意识，让我能在灵性天空之下操纵‘岛屿’上发生的一切，从而对抗真正意义上的读心**……”
- **奥黛丽的反制技巧（重要人物成长）**：
  - 她采取的双线策略：“一边暗中影响‘岛屿’的变化，一边在现实世界回应起沙发上悠然坐着的赫温·兰比斯”。
  - **向“岛屿”说谎、借“岛屿”诚实（重要）**：她刻意让“心灵岛屿”表现出真实的尴尬（“小孩子般吐了吐舌头”），因为“**尴尬往往就意味着说的是真话**”。
  - 她的表述中也混入真话（“我的未来规划里，一直有成为心理医生这个选项”“莫名觉得体内有什么事物哗啦破碎，融入了我的血液，并让我隐约看见了一颗又一颗虚幻的星辰”）。
- **赫温·兰比斯透露的重要知识（极重要）**：
  - **“扮演法”的官方态度（重要）**：他说奥黛丽“**很有天赋，竟然自己摸索出了‘扮演法’**”：“**就是你理解的那个意思，按照魔药的名称扮演，总结出相应的守则。这是消化魔药、减轻负面影响的有效办法。不过，在序列6之前，我们并不提倡成员用这种方法加速魔药的消化，所以不会教导**，谁知你却自己摸索了出来。”
    - **原因（重要）**：“**这会让成员变得不像自己，有的甚至会被魔药内残留的影响同化。**”“简单来说就是，**前面三个序列慢慢掌握力量，一点点适应超凡，让自我意识更加深刻更加鲜明更加成熟，有助于后面对抗‘扮演法’带来的一些问题。**”“当然，我只能对‘观众’途径给出意见，至于其他非凡途径，我并不清楚会不会这样……”
    - 奥黛丽的判断：“**小‘太阳’提过，‘扮演法’的注意事项有‘记住，你只是在扮演’这一条……我感觉这更加恰当**”→ 她提醒自己要加强自我意识。
  - **晋升条件（重要）**：“你确实有天赋和资格申请序列5‘**梦境行者**’的魔药配方，但在此之前，**我会陆续给你一些任务，这既是公平的需要，也是对你能力的锻炼**，因为**等你成为了序列5，就将领导两到三个心理研讨小组，你的每一次判断每一个选择都会影响手下成员的未来，乃至他们的生命**，所以，我们不能让严重缺乏事务处理能力的人晋升序列5。”
  - **第一个任务（极重要）**：“**新党和保守党的隔阂越来越大，冲突越来越多，王国内部已出现了一定程度的撕裂，我希望你能留意你父亲霍尔伯爵的态度，将他对某些议案或事务的看法转达给我**，放心，这不会对他造成损害，我们只是希望弥补裂痕。”
    - **关键危险**：“他最后半句话其实没有逻辑支撑，只是一个承诺，但随着奥黛丽‘心灵岛屿’上那个赫温·兰比斯**抬起右手，按了按额角，奥黛丽竟觉得他说的很有道理，深信不疑**。浮于心灵世界半空的她旋即清醒过来，**发现了不对**。”
