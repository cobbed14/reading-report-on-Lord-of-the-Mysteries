# 《宿命之环》第三卷《阴谋家》第188—191章 考据

批次区间：[1592622, 1606197)，下一位置为第一百九十二章《两个小孩》。分两次提取（卷三188—189、190—191），正文完整返回，无截断。

**★★★★★本批有两条重量级的线：一是"腓力将军"这条线查到尽头——他极可能是假死，其"非凡特性"也疑为仪式制造的假象；二是"旅舍"这条线第一次"撞到了人"——剧作家加布里埃尔已经变成那种"无法触碰、无法正常看见"的怪物，而源头指向了人体模特萨法莉与那场画展。同批还完成了**芙兰卡正式入会**，并由此引出"原初魔女"的三段尊名（还有两段未公开）、"黑之魔女"克拉丽丝、以及"铁血十字会偷运进特里尔的那件物品"这条旧线索的重新激活。**

## 一、腓力将军这条线（第一百八十八章）

- **【★★★★★"女神庇佑"的解释】**：**"这是信仰了黑夜，还是哪位邪神……从实际表现看，应该是邪神……"**
  - **卢米安的感慨极准**：**"难怪信仰邪神的人都喜欢把父母、配偶、孩子发展成同信，要不然，再是小心谨慎，很多细节也瞒不过彼此熟悉日夜相处的家人……"**
- **【★★★★★三条关键口供】**：
  1. **死因**：**"他半夜心脏绞痛，还没来得及送去医院，就不行了。"**
  2. **尸体**：**"接受过净化，烧成骨灰，送到了埃拉托区的家族墓园里。"**
  3. **"非凡特性"的去向（最重的一条）**：**"等着仆人到来背着他下楼坐马车时，他艰难地告诉我，说，如果他死了，身上有什么奇怪的变化都不用惊讶，将出现的东西收起来，留给孩子们。……葬礼的时候太乱，我又太伤心，那东西不见了，再也找不到了……"**
  - **其形状（决定性细节）**：**"那是他的拳头，变得没有了皮肤，关节像是黑色的金属，很锋利，轻松就切断了椅子的靠背……"**
  - **卢米安的判断（重要）**：**"他甚至觉得对方的非凡特性并没有真正析出来，安妮丝看见的现象和收起的物品是相应能力或者仪式制造出来的假象，后续自然消失不见。"**
- **【★★★★★"假死"的外形规律（一条极重要的设定）】**：**"按照'正义'女士的说法，这应该只牵涉到旧命运的失去和新命运的获得，不会改变本身的外形。"**
  - **腓力的外形记录**：**"个子不是太高，从周围的参照物看，大概一米七出头的样子。他头发浓密，略微卷起，眼睛不大，却有种老鹰盯着猎物的锐利，嘴巴周围胡须修剪得很整齐，尖端甚至涂着石蜡，鼻梁较有特点，仿佛被人打断过又没有愈合好，以至于中段隆起一截。"**

## 二、"寻梦者"慈善组织被焚（第一百八十八章）

- **【★★★★★"命运不让你有收获"这一判断（极重要）】**：**"我们来晚了……"——"不。可能只是命运不想让我们有收获，即使来得再早，也会看见类似的事情。"**
  - **其补充**：**"这至少说明我们走在正确的路上。"**
- **【★★★★★安东尼·瑞德的一句"誓言"（本批最动人的一段）】**：**"也许，我在那场袭击里就已经死去，现在活着的只是一个追逐真相，试图复仇的恶灵。我可以被毁灭，但我不能放弃。"**
  - **卢米安的回应**：**"欢迎坠入复仇的地狱。"**
- **【★★★★★"魔术师"女士的关键指导】**：
  - **"所有命运的交织，都在演绎着一场戏剧。"**
  - **"之后再有线索，重要的先告诉我，不太重要的自己一个人去调查，你体内封印着忒尔弥波洛斯，这是可以激起命运之河涟漪的沉重石头，不会那么容易被影响，而其他人不行。"**
  - **"另外，我们也会再做别的尝试。"**

## 三、加布里埃尔的失踪与"旅舍"（第一百八十九章）

- **【★★★★"三流作家"酒吧与地下文学产业链】**：**"我们没有署名权，只是老板的写作工具，他支付我们固定但不多的稿酬，提出写作的方向和要求，最后通过自己的渠道卖出去。"**
  - **一位"启蒙者"的自嘲**：**"《追逐狗的僧侣》和它的续篇《追逐僧侣的狗》，这都是我写的，但它们署得不是我的名字。"**；其名为**"拉贝"**。
- **【★★★★★加布里埃尔的房间与那杯水的"位移"（极漂亮的伏笔）】**：**"他端起书桌上的白釉瓷单耳水杯，发现里面还有三分之一的冷水，表面浮着许多正常人难以看清楚的灰尘。'至少有一天了。'"**
  - **转折点**：**"被他挪至手稿旁的那个白釉瓷单耳水杯不知什么时候已回到原本的位置！"**
- **【★★★★★那个未完成的剧本（本批最妙的"文本内线索"）】**：
  - **梗概**：**"一名落魄的作家遇到了一个被逼加入黑帮的女人，两人在绝望、痛苦、煎熬、恶劣的日常生活里互相安慰，彼此鼓励，用肉体温暖着对方的心灵，后来，作家得到报纸主编的赏识……而那个依旧沉沦在黑帮的女人选择消失。"**
  - **那段内心独白（本章的题眼）**：**"她来了；我的爱人从黑夜里来了。她走了；我的爱人走向了远方的旅舍……"**
  - **原型的辨认**：**"这个剧本的主角原型是加布里埃尔本人……至于女主角，那个沉沦在黑帮还不断鼓励男主创作的女人……女主角的身份、背景、黑帮经历糅合了我和查理的情况，与男主的互动则另有其人……人体模特，画家的人体模特！萨法莉搬走前和加布里埃尔睡过一晚！"**
  - **卢米安的结论**：**"他觉得问题的源头应该就是那位人体模特萨法莉！这位小姐曾经跟随一名画家去海边小城充当模特……"**；**"萨法莉搬去的地方是'旅舍'？"**

## 四、"窥秘眼镜"与"真实之眼"的第一次联用（第一百九十章）

- **【★★★★★"窥秘眼镜"下的世界（极好的一段描写）】**：**"床铺压着书桌，书桌靠着天花板，天花板后方是自来水龙头，自来水龙头则仿佛安装在衣柜内部……它们如同一块块半透明的画布以叠加的姿态映入了卢米安的眼眸。"**
- **【★★★★★加布里埃尔的"告别"】**：**"衣柜的侧面，一张略显苍白的脸孔凸显了出来。那脸孔棕发蓬松，自然分开，黑框眼镜之下是深褐色的眼眸，俨然便是……加布里埃尔。这位剧作家望着卢米安，脸上露出了略显空洞和扭曲但又实实在在的笑容。他的右手从虚空里伸了出来，轻轻挥了挥。"**
- **【★★★★"真实之眼"的第一次使用】**：**"听见遥远的天边似乎有一阵阵语速极快的声音传来，而紫色血管纠缠成的镜片紧贴着他的眼睛，让他看到了淡淡的血液、层叠的色块、有三分之一融入这幅场景的房间和毛玻璃式的无形帷幕。"**
- **【★★★★★卢米安的一次完整排除（极严密的推理）】**：
  - **"除开状态特殊的我，芙兰卡知道'旅舍'，简娜知道'旅舍'，安东尼·瑞德、画商德丽莎、魔女教派在特里尔的成员、'极光会'的K先生和'永恒烈阳'教会的大量'净化者'也都知道'旅舍'……却一个都没出问题……"**
  - **三类已知案例**：**"'至福会'的碧翠丝是知道'旅舍'在哪里，要去取一幅画；'罪人'的布瓦尔是预言到了与'旅舍'相关的那场灾难；'寻梦者'慈善组织是大概率在赞助与'旅舍'相关的画家、作家和别的邪神信徒。"**
  - **对加布里埃尔的疑问**：**"他最近会不会遇到了某些事情，导致他对'旅舍'的认识加深，或者发现了萨法莉的踪迹？"**
- **【★★★★★一条关键的新线索】**：**"我们最后一次见加布里埃尔是前天，我们一起去特里尔艺术中心看了一场画展。"**

## 五、芙兰卡正式入会（第一百九十章末至一百九十壹章）

- **【★★★★★"铁血十字会偷运进特里尔的物品"（旧线索重启）】**：布朗丝的条件是——**"我们收到情报，'铁血十字会'在几个月前通过地下隧道将一件物品秘密弄进了特里里，你如果能弄清楚它是什么，现在被谁掌握着，就可以得到'痛苦'的魔药配方。"**
  - **芙兰卡的联想**：**"她和卢米安为了帮这位萨瓦党的走私头目找回弟弟找回运送的物品，被一个奇怪的镜中世界吞入，差点没能逃出来。她还因此得到了一面造型古典的纯银镜子。"**
- **【★★★★★"黑之魔女"克拉丽丝（新人物，极重要）】**：
  - **身份与外形**：**"身穿黑色宫廷长裙的女士，她深灰的眼眸明亮中暗藏忧伤，乌黑的头发整齐盘起，但遗漏了几缕……红唇微翘，下巴优美，轮廓柔和。"**
  - **她就是音乐会上的那位"克拉丽丝"**：**"她作为现场最美丽的女士被邀请上台，与乐队合影留念！"**
  - **"黑之魔女"这一称号的分量**：**"有这类颜色称号的魔女即使在魔女教派的半神里也属于佼佼者，其中有几位还疑似天使……"**
- **【★★★★★"原初魔女"的尊名（本批最重的设定之一）】**：
  - **三段**：**"所有灾难的源头，毁灭与末日的象征，执掌混沌的魔女……"**
  - **一条极重要的补充**：**"'这不是原初的完整尊名，还有两段不是你现在能知道的。'"**
- **【★★★★★"原初魔女"雕像（一件极好的道具）】**：**"一尊白骨雕成般的神像。那神像只有巴掌大小，隐约能看出是个漂亮女子，头发一直延伸到了脚踝位置，根根清晰，如同毒蛇，而在每根头发的顶端，都雕刻着一只眼睛，它们有的睁着，有的紧闭。"**
  - **其功能**：**"有反占卜、预警等能力，也可以帮助你举行仪式。"**
  - **其要求**：**"你每天都要向它祷告。"**
- **【★★★★★祷告中的幻象（极重要）】**：**"其中一根蟒蛇般的藤蔓探向了芙兰卡，顶端张开了一只幽蓝色的竖眼。它随之映出了芙兰卡的身影。那身影急速扭曲，变成了一名满脸血污的男子……这是以前的她，弗兰科·罗兰！"**
  - **芙兰卡的判断（极关键）**：**"'原初魔女'和地底那个镜中世界似乎有非常密切的联系。她在那个镜中世界内也碰到过以前的自己！而这次，幽蓝竖眼内映出的同样不是芙兰卡，是她以前的模样，弗兰科·罗兰！"**
- **【★★★"黑之魔女"的一项任务】**：**"你这段时间要盯紧'铁血十字会'，尤其是加德纳·马丁，他们一有异动，你就立刻联系布朗丝。"**

## 八、整合包可用要点小结

- **【★★★★★"假死不改变外形"这条设定极好用**：**"只牵涉到旧命运的失去和新命运的获得，不会改变本身的外形"**——这给"认出假死者"提供了唯一的抓手：**凭外貌细节**（腓力那截被打断过的鼻梁就是最好的标记）。
- **【★★★★★"命运不让你有收获"这一写法**：**"即使来得再早，也会看见类似的事情"**——把"线索总是断掉"解释成"命运层面的遮蔽"，既合理化了剧情，也提高了对手的层次。
- **【★★★★★"用一件物品的位移来暗示"看不见的存在"**：**水杯从手稿旁自己回到原位**——这是"不可触碰的存在"最经济也最恐怖的写法。
- **【★★★★"把线索埋在角色自己写的作品里"**：加布里埃尔的剧本既是"人物弧光"，又是"情报载体"（那句"我的爱人走向了远方的旅舍"）。
- **【★★★★"两位大阿卡那给出的行动原则"**：**"重要的先告诉我，不太重要的自己一个人去调查"**；**"你体内封印着忒尔弥波洛斯，这是可以激起命运之河涟漪的沉重石头"**——把"主角的特殊性"解释成"抗干扰能力"，非常巧妙。
- **【★★★"黑之魔女"这一称号体系** 可作为"高位魔女分级"的现成设定。
- **人物**：**卢米安**、**安东尼·瑞德**、**安妮丝（腓力遗孀）**、**拉贝（地下作家）**、**加布里埃尔（已异变）**、**萨法莉（关键关联者）**、**芙兰卡**、**布朗丝·索伦**、**克拉丽丝（"黑之魔女"）**、**"魔术师"女士（信）**。
- **地点**：**3区利沃街9号**、**2区圣瓦罗街11号（"寻梦者"）**、**2区圣米歇尔街34号503**、**"三流作家"酒吧**、**特里尔艺术中心（"未来印象"画展）**、**夏约镇葡萄庄园圆亭**。
