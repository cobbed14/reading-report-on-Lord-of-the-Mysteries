# 《诡秘之主》第五部《红祭司》第53—56章 考据

批次区间：[3505011, 3518686)，下一位置为第五十七章《间奏》。分两次提取（53—54、55—56），正文完整返回，无截断。

## 特莉丝教唆谢尔曼（第53章，极重要）

- **休的跟踪技巧（重要）**：她放弃马车与脚踏车，改用“**有轨公共马车**”（“双层车厢”“上下两层总计能载近五十人”“拿出几枚1便士的铜币”），并借“**治安官**”的超凡感应与不远不近的距离，隐约把握目标的“**当前的位置和预定的方向**”。
  - 关于自行车的观察：“这种又叫**自行车**的交通工具比我想象得有用啊……**这能节省坐马车的开销或者步行的时间**……唯一的问题是，**这种交通工具目前式样还很少，都是高座位的类型**……”
- **谢尔曼（重要）**：“休看见了之前遍寻不着的**谢尔曼**！这个**自认为是女性的年轻男子**正抱着一个装着好几根长条面包的纸袋和一叠报纸，进入一条狭小的巷子。他的**及肩棕发又长长了不少**，**灰色的条纹裤颇有点紧身**。”
  - 休的判断：“谢尔曼**退掉在东区租住的房间，搬到了这边**？”→ 因正在跟踪目标，她“按捺下了跳出马车、追上对方、询问最近情况的冲动”。
  - “他似乎已具备不错的**反跟踪技巧**”（“穿过巷子和街道，绕了好大一圈，才进入一栋公寓内”）。
- **特莉丝与谢尔曼的对话（极重要人物线）**：
  - 特莉丝的形象：“一位身穿黑色长裙的少女。这少女有一张**甜美温润的脸庞**，有**妙曼难言的身姿**，哪怕站在窗口、挡住了阳光，让自身所在显得阴暗，**也仿佛镀上了一层黄金，愈发圣洁和美丽**。”
  - 谢尔曼的挣扎：“我，我不知道，**我喜欢的明明是男性**，为什么，为什么看到你，还是会有很多奇怪的想法……”→ 特莉丝：“**女性也会欣赏漂亮有魅力的同类。**”
  - **谢尔曼的悔意（重要）**：“**我真的做不到教唆别人去偷窃、抢劫、杀人，这太坏了，太可恶了！**”“就连最开始，**你让我刺杀的那些人，我现在也感觉做得太过分了**，虽然他们确实有骂我、打我、歧视我、散播我的坏话……**但是他们的行为没到需要用生命来偿还的程度。**”
  - **特莉丝戳破旧账**：“你当初不是这么说的，你痛恨着他们……**一获得非凡能力，就迫不及待地想要报复他们，我只是稍微提了一句，你就自己策划了多起刺杀事件**，我一直都记得**你身上沾满鲜血、瑟瑟发抖又狂热满足的样子**。”
  - 谢尔曼：“**我现在每晚都在做噩梦，梦到他们血淋淋地围着我，追赶我，撕咬我……**”
  - **特莉丝的“职业话术”（重要）**：
    - “**这是刺客必然会有的心理蜕变阶段**，你想想，以前那些人欺凌你的时候，你是不是恨不得杀掉他们？”→“**你就当你是被欺凌时反抗，才杀掉了他们。**”（“她的话语自有一种**让人愿意倾听、愿意相信**的意味。”）
    - “而且，**他们活着的时候都不是你的对手，死了又有什么好怕的？**就算他们变成了鬼魂、变成了幽灵，也没什么，**你只要认真完成‘仪式’，再服食一次魔药，就能将那些魂灵全部烧死！**”
    - 对“教唆”的辩解：“**那是他们本来就拥有的恶念，和你没有任何关系**，即使没有你，在特定的时刻特定的场合，这些恶念也可能爆发出来。”“我给你安排的任务**都与黑帮有关**……能让他们内讧、彼此残杀，是对你和像你一样的**东区无辜居民的仁慈与怜悯**。”
  - **交易条件（重要）**：“你距离最终的目标只剩一步了，只要**完成剩余的‘仪式’，就能喝下第三剂魔药，彻底转变为女性**。”“到时候，你就可以用上之前取好的‘**雪曼**’这个名字……**以一个女孩的身份离开贝克兰德，前往间海郡或者迪西郡，开始全新的生活**……”“**你不是说，为了找回自己，可以付出一切吗？**”
  - 结果：“谢尔曼嘴唇翕动了几下……‘特莉丝女士，我明白了，我，**我会按照你吩咐去做的。**’”
- **报纸上的伏笔（重要）**：“那叠报纸已然散开，显露出一份的某条报道：‘……**来自迪西的富翁道恩·唐泰斯先生有意收购拉里维钢铁公司**，认为它具备相当不错的盈利能力和发展前景……’”
  - 克莱恩的回应（重要）：“**这新闻纯粹是编造的**，我和拉里维钢铁公司的拥有者**菲尔·拉里维**先生只在上周的舞会里见过一次，聊了几句。”
  - 瓦尔特的补充：“**拉里维钢铁公司确实在寻求买家**，目前有意向的人不少。”→ 克莱恩判断：“**也就是说，这个消息是菲尔自己找记者放出去的，以便卖出更好的价格？**”
  - （即：这条新闻是**特莉丝引导谢尔曼注意到道恩·唐泰斯**的伏笔。）

## 道恩·唐泰斯＝阿蒙顶替的目标？（第54章，极重要）

- **克莱恩的日常监控**：“他最近几天坚持在做的事情”——透过“赢家”恩尤尼的祈祷光点，“**一个又一个审视那里的人类和动物，看是否能发现一个黑发黑眼戴单片眼镜的男子**”。
- **海柔尔的异常（极重要）**：“一位有**墨绿色波浪长发和深棕色明亮眼眸**的少女从马车上走了下来……**神情舒展中带着点愉悦**。”
  - 克莱恩的判断：“**这是绝对反常的表现！**”→“以她冒着危险也要去郊外庄园通知老师的表现看，**她不是那么冷漠自私的人**……她现在的状态说明，**她确认她的老师、那位老鼠半神，没什么事情，甚至还从对方那里得到了一定的奖赏**，也许包括各种超凡世界的常识……”
  - **核心结论（重要）**：“排除掉种种不可能后，剩下的就是真相……**阿蒙不仅汲取了老鼠半神的非凡特性，还窃走了‘他’的命运，顶替了‘他’的身份！**”
  - 他的评估：“阿蒙最恐怖的一点是，**没人知道祂会以什么方式什么身份出现，哪一天马赫特议员戴上了单片眼镜，花园里的蚊虫同时转过了身体，都不是不可能**，所以**大致把握到阿蒙会以什么身份出现之后，克莱恩难免踏实了一些**。”
  - 且不放松：“根据帕列斯·索罗亚斯德的说法，**阿蒙绝不会只以老鼠半神的身份出现**，不能因此大意……”
- **莎伦的来信（重要）**：蕾妮特·缇尼科尔送来莎伦的信，内容仅一行：“**埃姆林·怀特在找玫瑰学派的人。**”
  - 克莱恩的推断（重要）：“**这绝对不是埃姆林自己的意图**……之前埃姆林提过，有位血族大人物要见他……**这是血族给他的新任务？**”→ 并推出：“既然莎伦小姐都知道了埃姆林在找玫瑰学派的成员，并向共同的朋友**夏洛克·莫里亚蒂大侦探**咨询这件事情，那说明这位血族寻求帮助的对象**肯定是‘勇敢者’酒吧的黑市军火商人伊恩**。”“这间接也表明，**埃姆林在之前的委托里，有发现莎伦或者马里奇的踪迹**，否则他不可能直接对一个普通人提玫瑰学派。”
  - **他的回信要点（重要）**：“这应该是**血族高层给埃姆林的任务**，他们**憎恶着玫瑰学派信仰‘原始月亮’的那些成员，并迁怒至玫瑰学派其他派系**……”；“**我怀疑‘欲望母树’有侵蚀‘月亮’领域权柄的意图**，但不解的是，**为什么‘原始月亮’的信徒要加入玫瑰学派，这位隐秘存在和‘欲望母树’的关系似乎很复杂，有敌对，也有合作，难以猜测……**”
- **蕾妮特·缇尼科尔的观察（重要）**：她依次说“**你……最近……活泼了……一点……**”“**表情……也……丰富了……不少……**”
  - 克莱恩的回应：“**总是戴着厚厚的面具不利于身心健康，通过半神之门后，愈发得注意这点。**”→“所以，若非必须掩饰和伪装的场合，他都**减少了用‘小丑’能力控制自己表情的次数**。”
  - （回收此前奥黛丽的建议“不要戴上那厚厚的面具”。）
- **马里奇现身（极重要）**：
  - 形象：“**外套没有扣上，露出里面白色衬衣和黑色马甲的年轻男子**，他**棕色的头发略显凌乱**，似乎没有好好地进行梳理，**褐色的眼眸则充满压抑的感觉**，仿佛在克制深藏的某种冲动。”→“**苍白如同死尸的脸庞**”“**身影隐有些透明**”。
  - 埃姆林的话：“**你们终于来找我了。**”→ 马里奇反问“你不害怕我是玫瑰学派的成员，专门来对付你？”→ 埃姆林：“**你以为我会不清楚玫瑰学派的历史，不知道之前发生的节制派叛逃事件？**”
  - **马里奇的提议（重要）**：“**如果真是这样，我可以用自己为诱饵帮你们钓出玫瑰学派的成员，但我需要一个确认。**”“我知道你无法做决定，你先回去请示血族的高层，**拿到必须的承诺**，之后，你知道在哪里可以找到我们。”
  - 他交付伊恩整理的**跟踪欧内斯·博雅尔的初步反馈文件袋**（“多位赏金猎人共同完成”）。

## “第一乐章”：针对欧内斯的行动（第55—56章，极重要）

- **埃姆林对情报的分析（重要）**：欧内斯“**最近每隔一天就会去圣乔治区一次，监督自己投资的家具工厂做改造**”→ 生活出现重复（“**每隔一天，活动场所重复，沿途路线重复，中午用餐地点重复**”）。
  - **三个候选场景**：①“他开办的那间家具工厂内部或门口”；②“他回家中途会停留用餐顺便喂鸟的**圣希尔兰广场**”；③“**贝克兰德大桥**——除非对方愿意绕很远的路，否则从家到圣乔治区必然会经过这里”。
  - **排除理由**：“贝克兰德大桥**出入通道太少，被守住两端就只有跳河才能离开**，属于蠢货的选择……”
  - **选定圣希尔兰广场的四条理由**：“圣希尔兰广场属于**圣希尔兰大教堂**，是**蒸汽教会在贝克兰德乃至整个鲁恩的中心，第二教廷**，符合‘倒吊人’先生的提议，能有效控制可能发生的冲突的程度，**干扰事后的占卜和调查**”；①欧内斯会在那里停留不短时间（在一家**西维拉斯风味**的餐厅享用午餐——他**出生于西维拉斯郡**）；②那里“集合了多条有轨马车的站点，人来人往，以中低层为主体，常有意外发生”；③“从那里出发，如果不过贝克兰德大桥，就会进入大桥南区，**与丰收教堂相隔不是那么远**”；④“**中午十二点整，圣希尔兰教堂会喷蒸汽，转杠杆，鸣大钟，没有谁的注意力不会被吸引**”。
  - **关键醒悟（重要）**：“**圣希尔兰广场简直太适合动手了！适合到近乎每个条件都满足！**”→“**圣希尔兰广场就是血族高层‘为他’圈定的行动地点！**”
- **血族一方的准备（极重要）**：
  - **米斯特拉尔伯爵**（重要新角色）：“身材瘦高，穿着参加宴会的晚礼服，**偏银的淡色头发与鲜红的眼睛**搭配出了略显妖异的俊美，嘴角始终噙着不太明显的笑容。”
    - 他的目的（重要）：“我们的准备连一位半神都能对付，何况这个还没成为子爵的小家伙？而且，**我们并不想真的做点什么，唯一的目的是确定和辨认**，这可比阻止某些人逃离简单多了。”
  - **欧内斯的全套装备与负面效果（极重要道具资料）**：
    1. “**玫瑰之誓**”（左手无名指，银为环、镶嵌幽蓝色的奇异宝石）：效果是“**可以让远处的米斯特拉尔伯爵共享他的视觉、听觉和嗅觉**”；负面是“**时不时让他的想法出现在米斯特拉尔伯爵的脑海中，而如果连续佩戴一周、未曾取下，那拥有对戒的双方很有可能相爱，无关性别和种族**”。
    2. “**月亮纸人**”（内侧口袋，与银制怀表放在一起）：效果是“**能代替他承受一次致命伤害或者直接针对精神体的攻击**”；负面“**几乎没有负面影响，仅会让人身体微微发冷**”。
    3. “**酒类克星**”（钻石领针）：效果是“**帮助他保持精力的充沛和思绪的清醒，提高对心智体领域法术的抵御能力**”；负面“**会持续性对肝脏和大脑产生损伤，如果佩戴时间过长，很有可能丧失一定的思考和逻辑能力，所以，每佩戴半小时就必须取下一刻钟**”。
    4. “**月光缎带**”（皮带）：效果是“**可以有效降低‘太阳’和‘闪电’的伤害**”；负面“**各种感官会变得更加敏锐，容易看到不该看到的事物，听见不该听见的声音，同时，佩戴者将间歇性浑身瘙痒**”。
  - 综合评价：“这些神奇物品或源于欧内斯的积蓄，或来自米斯特拉尔伯爵的赐予，**将欧内斯打造成了一个难以被快速解决和控制的‘目标’**。再加上**血族子爵对梦魇类影响的天然抵抗力**，欧内斯现在**几乎不存在弱点**，哪怕面对半神，只要对方不展露神话生物形态，也能支撑一阵。”
- **行动过程（极重要，分工兑现）**：
  - **第一步（伦纳德：“星星”）**：“一只**透明模糊的狼类幽灵**从窗外扑了进来，**向自己扔出了容纳于体内的一朵玫瑰**”，同时马匹“像是做了场噩梦一样”发疯 → 欧内斯“**已是进入了沉眠**”。
    - 执行者形象：“无轨公共马车内，一个**墨发碧眼的年轻男人**穿着薄薄的风衣，背对着道路中央而坐，专注地翻阅着一本**封皮坚硬颜色铜绿的笔记本**。”
  - **第二步（奥黛丽：“正义”的“天使”幻象）**：米斯特拉尔借“玫瑰之誓”共享视野时，“那黑沉的‘视野’内，一点微光跳跃了出来……从中走出了一个**背生十二对漆黑羽翼的金色人影**！那一对对翅膀相继张开，覆盖了米斯特拉尔的‘视界’，**其上明暗交错，形成了一个又一个神秘复杂的符号。它们与金色的身影不分彼此，既神圣又堕落，既光明又黑暗。**”→ 米斯特拉尔“**天使！**”→“**中断了刚才的想法**”。
  - **第三步（奥黛丽的催眠，借“报童”掩护）**：欧内斯醒转后“看见了一双**剔透如同宝石清澈仿佛湖水**的眼睛”，并“感觉有份报纸递来，塞入了自己的掌中”。
    - **催眠指令（重要）**：“**拿着报纸，跟随埃姆林·怀特……**”以及后续那句听不清的“**第一重催眠清醒后，将身上的物品砸向埃姆林·怀特。**”
    - 报童“**有着清秀的脸庞，头发凌乱垂下，遮住了眉毛**”，边走边“**将左手不知什么时候戴上的黑色薄纱手套取了下来**”，且“**衣物有所收缩，显现出了胳膊位置的一道凸起**”——即奥黛丽（或秘偶）伪装。
  - **第四步（圣希尔兰教堂的十二下钟声）**：“白色的蒸汽从圣希尔兰教堂顶端的根根烟囱里喷了出来，**赞美的圣歌伴随着巨大齿轮和杠杆的转动**……广场之上，所有人都停住了脚步……**唯有被喂养的白鸽们，同时振翅飞起，冲向半空。**”
  - **米斯特拉尔的收手分析（重要）**：“**刚才那借助天使位格的能力绝不属于中低序列者**，也就是说，**埃姆林·怀特背后的势力在附近至少暗藏着一位半神**……”“**当自己处于容易被发现的位置，而对方不知藏于哪里时……强行追赶只会出大问题。**”
    - 且“**在贝克兰德，在圣希尔兰教堂周围，这是形同自杀的事情**”；“既然对方的半神都没有亲自下场，只是做了次辅助，那自己直接动手和追赶，**实在有失体面，侮辱了血族伯爵的名誉**”。
  - **第五步（埃姆林的收尾，人物刻画）**：他给车夫**100镑现金**（“**100镑足以买一辆新的出租马车了，而且，还剩很多！**”），从而化解了车夫“讹诈／卖马跑路／宁愿坐牢”的三重绝望盘算。
  - **第六步（“埃姆林跑、欧内斯追”）**：埃姆林“**时而绕圈，时而斜插，时而从另一条路返回之前经过的地方，让人无法猜到他的目的地是哪里**”，欧内斯“**就像看见了红色旗帜的公牛**”；最终两人抵达**大桥南区的月季花街**，冲进**丰收教堂**。
  - **第七步（教堂内的“容器”效果）**：“一声响后，米斯特拉尔脚底的石砖一下粉碎”；教堂内“**整个教堂变得极为厚重极为牢固，似乎与大地连成了一体**”（乌特拉夫斯基神父的“大地”权能）；欧内斯随即执行第二道指令，**把腰带、领针、银制怀表、装满钞票的钱夹乃至一切物品砸向埃姆林**。
  - **章末的揭底（极重要）**：“啪！他手里的报纸掉落于地，**摔出了里面夹着的一张纸牌**。那张纸牌上，画的是一个**坐在石椅上，拿着剑和天平的公正女神**。塔罗牌，‘**正义**’牌。”
