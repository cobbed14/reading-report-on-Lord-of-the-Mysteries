# 《宿命之环》第二卷《逐光者》第40—41章 考据

批次区间：[531580, 538380)，下一位置为第四十二章《诱惑》。分两次提取（卷二40、41），正文完整返回，无截断。**本批含“托钵僧侣”恩赐的获得与五个仪式魔法的完整清单，以及被封印的“污染”首次开口——自称天使的“忒尔弥波洛斯”。**

## 一、五个仪式魔法：晋升“托钵僧侣”（第四十章，极重要）

- **【他的谨慎（极重要）】**：“‘**那个仪式涉及两位隐秘存在和能让一个村落循环的污染，过程中要是出点什么问题，别说“金鸡旅馆”了，整条乱街都未必能够保住，不知道会死多少人。**’”“‘**他打算天亮之后，进入地底，找一个位于深处的采石场空洞作为仪式之地。**’”
- **【仪式地点与环境（极重要）】**：“‘**他依靠猎人对环境的记忆能力，不断地下行着，终于抵达了一处足有两三个“金鸡旅馆”规模的采石场空洞。这里的石头缝隙里长着一些白色的蘑菇，稀稀拉拉，数量不多。**’”
  - **一段风物（极重要）**：“‘**据查理说，乱街和周围区域有不少人在地底找类似的空洞种蘑菇，以填补家用，增加食材，很多年前，“特里尔蘑菇”就已成为这类种植物的代名词**’”
- **【仪式的过程与一个进步（极重要）】**：
  - “‘**他找了一块半米高的石头，将融合了自己血液的麝香蜡烛摆在了上面，而另外一根置于更靠近他的位置。**’”
  - **【一个重要进步（极重要）】**：“‘**和上一次祈求“舞蹈家”力量不同，卢米安完成这些事情后，灵性依旧充沛，轻松就进入了那种较为空灵可以举行仪式的状态，无需再借助熏香的帮忙。**’”
  - **咒文（极重要）**：**“宿命的力量啊！”**→**“您是过去，是现在，也是未来；您是原因，是结果，也是过程。”**
  - **异象（极重要）**：“‘**“灵性之墙”内，无形的风全部染上了黑色，周围弥漫起了淡淡的灰雾。那些石头，那些瓶子，像是变成了柔性物体，一个接一个扭曲了起来。**’”“‘**代表神灵的烛火膨胀开来，足有拳头大小，银白带黑。**’”“‘**卢米安的皮肤表面，那些石头之上，一个颗粒接一个颗粒冒了出来，蠕动着，延伸着，随时可能钻出。**’”
  - **【他如何撑住（极重要）】**：“‘**他唯一能做的就是在这狂风暴雨掀起的“海浪”里，艰难维持代表自身理智的那条“小船”。**’”“‘**但那淡雅清甜的香味始终萦绕于他的鼻端，让他的暴戾、烦躁一次次涌起又一次次退去。**’”（**灰琥珀香水的作用在此再次显现**）
- **【晋升的结果：四项收益（极重要）】**：
  1. **忍受能力（极重要）**：“‘**我对各种较极端环境的忍受能力变强了一点……呵呵，这好处是不用买冬装和夏装？**’”
  2. **【对运势的直觉（极重要）】**：“‘**那是对运势的直觉！现在的他能粗略地感应到别人最近拥有哪些运势，比如，好运，厄运，血光之灾，桃花运等，但看不到具体的情况。**’”“‘**也就是说，卢米安能发现别人处在霉运状态里，但无法知道他会怎么倒霉，倒霉多久。**’”
     - **他的评价（极重要）**：“‘**不愧是祭祀宿命力量的僧侣……**’”“‘**虽然他完全不懂占卜，但在能看到粗略运势的情况下，相应的话语还不是任由他编造？**’”
  3. **祭祀知识（极重要）**：“‘**前者弥补了他在神秘学领域的许多不足**’”
  4. **【五个仪式魔法（极重要，本批最重要的清单）】**：“‘**那五个仪式魔法分别是“造畜之术”、“预言之术”、“转运之术”、“替代之术”和“驱鬼之术”。**’”
- **【五个仪式魔法的完整机制（极重要，逐条）】**：
  - **“造畜之术”（极重要）**：“‘**通过仪式魔法，利用羊皮、牛皮等动物皮毛，让祭坛内的目标变成对应的动物，这也能对自己使用，只要掌握了提前设定好的解除咒文，或者等到仪式效果结束，就能变回人类身体，而变成动物时，基本无法说话，也不能使用绝大部分超凡能力。**’”
    - **祈求对象与代价（极重要）**：“‘**“造畜之术”的祈求对象既可以是那位以宿命为名的隐秘存在，也可以是这次“附赠”的那些不知道指向谁的尊名，还能是自己。**’”“‘**在“造畜之术”里，对位格的最低要求是达到序列7“受契之人”，位格越高，仪式就越可能成功，效果也越好。**’”
  - **“预言之术”（极重要）**：“‘**它的全过程是，搜集蛇的毒囊、鹰巢里的石头等材料，利用仪式魔法制造出一种奇怪的药水，然后找到一具死亡不到七天，还未被烧成骨灰也未接受过净化的尸体，将药水灌入他的口中，三十秒后，这尸体会短暂复活，回答施术者关于未来的三个问题。**’”
  - **“转运之术”（极重要）**：“‘**利用仪式魔法制造关联自身霉运的某种物品，然后将那物品送出去，借助他人打开、食用、踩到、佩戴该物品的某种行为，将霉运转移到他那里，实现自身的转运。**’”
  - **“替代之术”（极重要）**：“‘**卢米安怀疑这是“猎命师”能力在低序列的某种反映，就像他要逃避苏珊娜·马蒂斯的威胁，必须先找一个流浪汉，让他以夏尔的名义生活一段时光，其间，必须住在207房间，使用卢米安全部的钱财，并得到查理等熟人的认可，建立起足够的神秘学联系，然后再举行仪式完成替代。**’”“‘**等到仪式结束，苏珊娜·马蒂斯之后报复的就是那个流浪汉，而不是卢米安。**’”
    - **他的保留（极重要）**：“‘**以序列8的层次使用“替代之术”，卢米安不确定能不能瞒得过接近半神的苏珊娜·马蒂斯，他甚至怀疑那个仪式魔法会直接失败。**’”
  - **“驱鬼之术”（极重要）**：“‘**这个仪式魔法确实能驱走怨魂乃至恶灵，并让它们不再纠缠，但有两个前提，一是知晓鬼魂的真名，拿到她生前长期携带的某样物品，二是具备足够的、用来举行仪式的时间。**’”

## 二、声音：被封印者的首次开口（第四十一章，极重要）

- **【他对“驱鬼之术”的分析（极重要）】**：
  - “‘**第二个前提就决定了“驱鬼之术”没法在激烈的战斗中使用，更适合查理之前屡次梦到苏珊娜·马蒂斯的那种情况**’”
  - **【他为何用不上（极重要）】**：“‘**而卢米安现在并未实质性地受到苏珊娜·马蒂斯的危害，顶多算是被她盯上，“驱鬼之术”缺乏对应的目标，驱无可驱。**’”“‘**以她之前展现出来的恨意和偏执看，必然是直接动手，使用各种超凡能力，务求将目标击杀于当场。**’”
  - **他的两个“设想”（人物素材，极重要）**：“‘**或者，让查理牺牲下自己，用动人的情话安抚苏珊娜·马蒂斯，陪她于现实做那件事情？他撑得越久，我完成“驱鬼之术”的希望就越大……**’”“‘**呵呵，这个办法怪怪的，有种地下文学的既视感……**’”
- **【一段极重要的社会考据：因蒂斯的出版审核与地下文学（极重要）】**：
  - “‘**当前的因蒂斯共和国，虽然以“自由”为口号，但实际上并不那么自由。**’”
  - **【其原因（极重要）】**：“‘**一方面是为了防止罗塞尔崇拜者寻求复辟，烧炭党人试图颠覆当前政权，反对派动摇执政党的威信，另一方面也是受到相对保守的“蒸汽与机械之神”教会和“永恒烈阳”教会的压力**’”
  - **【其手段（极重要）】**：“‘**他们甚至会安排密探或者发展某些作家为密探，监控那些活跃的创作者**’”
  - **【其后果（极重要）】**：“‘**有禁止就有违规，特里尔发展出了一个蓬勃的地下文学市场，并外溢到了其他省份。**’”
  - **一本具体的书（极重要）**：“‘**那本书集批判教权，批判神职人员的奢侈堕落和传播情色内容为一体，书名叫《追逐狗的僧侣》。**’”
- **【他对五个魔法的综合评估（极重要）】**：
  - **“造畜之术”的评价（极重要）**：“‘**“造畜之术”既非常神奇，又邪恶，诡异，令人恐惧。这用得恰当能发挥不可思议的作用，比如，把俘虏变成羊、牛、马等动物，光明正大地带走，比如，能让自身以动物的身份混入原本没法混入的地方，但大部分时候，尤其是激烈的战斗里，这个仪式魔法几乎派不上用场。**’”
    - **一个极重要的推测（极重要）**：“‘**他怀疑这五个仪式魔法在更高序列能够简化，能初步应用于实战，比如，只要用羊皮裹住了敌人，念出了预先设定好的咒文，就能直接将他变成一只羊。**’”“‘**相当于序列7的“受契之人”看起来没法做到，序列4的“环中人”位格又太高了，和这种简陋的法术不匹配……所以，是序列5的“猎命师”附带类似的简化，还是我目前不知道名称的序列6？**’”
  - **“转运之术”的限制（极重要）**：“‘**他觉得目前只能以“帮助”别人为主，应该没法对自身使用，因为他的命运深刻地被体内封印的污染和封印污染的那位伟大存在影响了**’”
  - **“替代之术”的评价（极重要）**：“‘**太过复杂，又会严重影响到卢米安的日常生活和别的任务，不是没有其他办法，他不会考虑使用。**’”
  - **“预言之术”的实用（极重要）**：“‘**“预言之术”是一个完成难度不算太高且颇为有用的仪式魔法。**’”
    - **他的两个计划（极重要）**：“‘**通过询问查理的未来分析苏珊娜·马蒂斯再次袭击的大概时间范围，以及，借询问路易斯·隆德的未来寻找普阿利斯夫人他们的下落。**’”
    - **【其材料清单（极重要）】**：“‘**狗的唾液、猞猁的内脏、鬣狗的舌头、牡鹿的骨髓、海怪或者水怪的肉块、蜥蜴的眼睛、鹰巢里的石头、蛇的毒囊和致命的草药**’”
- **【本批最大的震撼：被封印者开口（极重要）】**：
  - **声音的来源（极重要）**：“‘**他听到了某个细微的声音。那声音正回荡在他的耳朵内！**’”“‘**那声音一阵阵响起，仿佛来自卢米安的脑海深处，来自他的身体内部，被血肉、脏腑和骨头阻挡，形成了回音，层层叠叠。**’”
  - **【它的自述（极重要）】**：“‘**卢米安·李！卢米安·李！**’”“‘**我是主的天使，忒尔弥波洛斯。**’”
  - **【它对“主”的描述（极重要）】**：“‘**主是旧日的支配者，序列之上的本源，伟大的“宿命之环”……**’”
    - **【一个极重要的反应（极重要）】**：“‘**这些话语仅仅只是出现在卢米安的脑海，就让他莫名恐惧，仿佛有目光穿透了星空，穿透了云层，穿透了地面那个特里尔，穿透了层层泥土，落在了他的身上。**’”“‘**骤然之间，卢米安不断地转身，不断地看向身旁，仿佛周围的黑暗里有一个又一个无形之人正盯着他。**’”“‘**就在这个时候，淡淡的灰雾不知从何处而来，笼罩了这片区域，卢米安的精神状态随之得到极大平复。**’”
  - **【他的态度（极重要）】**：“‘**他嗤笑起那个自称天使的忒尔弥波洛斯：“你就是被封印在我体内的那个家伙？”**’”“‘**也不知道是有非凡特性的真正天使，还是只有恩赐的天使级仆从……**’”“‘**这样的挑衅让卢米安体内的魔药似乎又消化了一点。**’”
  - **【它开出的条件（极重要）】**：“‘**只要你遵循我的吩咐，让我从封印中出来，我就会帮你复活奥萝尔·李。**’”“‘**我主的力量涉及过去、现在和未来，能让命运构成一个循环。**’”“‘**到时候，我会让奥萝尔·李的灵魂碎片回到降临仪式开始前的状态，而你只需要给她准备一具有生命活性的身体。**’”

## 四、整合包可用要点小结

- **【“托钵僧侣”恩赐的四项收益（极重要）】**：①**对极端环境的忍受能力提升**；②**获得对“运势”的直觉**（**能粗略感应他人近期是好运、厄运、血光之灾或桃花运，但看不到具体情况**）；③**大量祭祀知识**（**弥补其神秘学不足**）；④**五个仪式魔法**。
- **【五个仪式魔法（极重要，完整清单）】**：
  - **造畜之术**：**以羊皮、牛皮等动物皮毛，使祭坛内的目标变成对应动物**（**可对自己使用**，**凭预先设定的解除咒文或等效果结束可复原**；**变身期间基本无法说话、不能用绝大部分超凡能力**）；**祈求对象可为那位隐秘存在、附赠的未知尊名或自己**；**最低位格要求为序列7“受契之人”**。
  - **预言之术**：**以蛇毒囊、鹰巢石头等材料制成奇怪药水，灌入一具“死亡不到七天、未烧成骨灰、未接受过净化”的尸体口中，三十秒后尸体短暂复活并回答关于未来的三个问题。**
  - **转运之术**：**制作一件关联自身霉运的物品并将其送出，借他人打开／食用／踩到／佩戴的行为把霉运转移过去**（**目前只能用于“帮助”别人，对己无效**）。
  - **替代之术**：**找一人（如流浪汉）以“夏尔”之名生活、住 207 房、花他的钱、并获得熟人认可，建立足够的神秘学联系后举行仪式完成替代**（**疑为“猎命师”能力在低序列的反映**；**极复杂、干扰大，且未必瞒得过接近半神的苏珊娜**）。
  - **驱鬼之术**：**能驱走怨魂乃至恶灵**，但**须知晓鬼魂真名＋持有其生前长期携带之物＋有充足仪式时间**——**故无法用于激烈战斗**。
- **【一条极重要的推测（极重要）】**：**这五个仪式魔法在更高序列应可简化、初步用于实战**（如**以羊皮裹住敌人并念出预设咒文即可使之变羊**）；**序列7“受契之人”似做不到，序列4“环中人”位格又太高**，**故简化版可能属序列5“猎命师”或某个未知的序列6**。
- **【因蒂斯的出版环境（极重要）】**：**虽以“自由”为口号，实则有严格的出版审核**（**防罗塞尔崇拜者复辟、烧炭党颠覆、反对派动摇威信，并受“蒸汽与机械之神”与“永恒烈阳”两教会压力**）；**官方会安排密探或发展作家为密探监控创作者**；**由此催生蓬勃的地下文学市场**（**奥萝尔曾好奇购入并禁止弟弟翻阅，其中一本为《追逐狗的僧侣》**）。
- **【本批最重大的情节（极重要）】**：**被封印的“污染”首次借力量联系开口，自称“我是主的天使，忒尔弥波洛斯”**，其“主”被描述为“**旧日的支配者，序列之上的本源，伟大的‘宿命之环’**”；**它提出以“助其脱困”交换“复活奥萝尔”**（**称其主之力涉及过去、现在与未来，可让命运构成循环，将奥萝尔的灵魂碎片回到降临仪式开始前的状态，只需为其备一具有生命活性的身体**）——**而卢米安的追问指向“降临仪式是否即制造一具身体以供降临”**。
- **人物与地点**：地底采石场空洞（两三个金鸡旅馆规模，长白色蘑菇）、金鸡旅馆 207、白外套街咖啡馆；**安东尼·瑞德**、**忒尔弥波洛斯（被封印者）**、**查理**、**路易斯·隆德**（线索）。
