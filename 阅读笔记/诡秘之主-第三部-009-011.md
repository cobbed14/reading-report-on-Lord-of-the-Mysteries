# 《诡秘之主》第三部第9—11章考据

- 连续正文区间：`[1741140, 1751553)`；下一章为第十二章《舌尖上的鱼人》，正文输出无截断。
- 【伦纳德】灰雾占卜确认巴布尔河谷聚会中出现者确为伦纳德本人，但他是教会调查员还是私下寻找复仇机会，当前没有前置信息可判定；克莱恩暂不接触，仅计划了解聚会后再决定是否匿名提醒。
- 【机械之心调查结论】调查认定夏洛克被动卷入、总体无辜且是阻止灾难的英雄；未解问题包括他向谁祈祷、何时认识阿兹克、如何逃出遗迹。霍拉米克认为只要没有重大问题，可以忽略其小缺点和秘密。
- 【地下遗迹善后】王室高序列当天行踪不明，地下遗迹被清空并隐藏，连阿罗德斯也无法完整还原；三教会继续联合排查，机械之心公开监控王室以形成警告。官方占卜认为绝望女士与芬克尔仍活着但失去自由，符合0-17的“消失而仍存在”效应。
- 【阿罗德斯观察限制】阿罗德斯能重现克莱恩攻击祭坛、万能钥匙破坏仪式及A先生被抹除的结果，却无法呈现遗迹内已经被隐藏的逃亡过程，并把0-17出现处显示为空白；其追溯并非无条件全知。
- 【格尔曼身份】1350年1月5日上午，克莱恩以格尔曼·斯帕罗登上白玛瑙号，开启约九天的普利兹至罗思德群岛航程。前冒险家克里维斯现任商人一家保镖，主动表明身份是海上同行间互不侵犯的默契。
- 【无面人守则探索】克莱恩认为“只能是自己”可能指剥离社交人格面具后的真实内心；短时变成因斯骗过守卫仅是能力运用，并未促进消化。有效扮演或需长期成为某人的社会身份、瞒过其亲友，但直接顶替活人过于邪恶，故拟寻找客死异乡且心愿未了者验证。均为当前推演，尚未形成最终守则。
- 【海上战斗常识】克里维斯提醒枪械子弹有限，海盗登船后近战武器仍重要；冒险家常选择避免无谓反抗，陆上赏金猎人的经验不足以直接适应海上规则。
- 【鱼人生态与狩猎】单只鱼人曾试图登船；鱼人倾向群居，成群会破坏船底，而航道附近群落已被风暴教会清除。猪牛内脏可作诱饵，胡椒使其短时兴奋失衡后疲惫，普利兹薄荷膏对其为血液毒素；步枪、毒刃与水手配合使普通人也有机会猎杀低级非凡生物，但仍存在逃脱风险。
