# 《诡秘之主》第六部《逐光者》第25—28章 考据

批次区间：[4119355, 4132973)，下一位置为第二十九章《两手准备》。分两次提取（25—26、27—28），正文完整返回，无截断。

## 一、思路很重要：帕列斯的“欺诈规则”方案（第25章，极重要）

- **帕列斯的建议（极重要）**：
  - 伦纳德问“你就不想趁这个机会为难一下阿蒙？”——帕列斯的回答是“**这能有什么好处？没有就算了。**”
  - **真正的建议（重要）**：“你那位前同事不是有‘**欺瞒**’符咒吗？也许可以从这上面想想办法。”
  - **核心思路（极重要）**：帕列斯的声音“忽然精神了一点”：“‘**欺诈**’返回后只能在原本身体所在地方的规则！”
  - 伦纳德的震惊与帕列斯的自嘲：“**比起‘欺诈’阿蒙，还是‘欺诈’规则容易不少，毕竟这个世界的底层是疯狂和混乱的。**”
  - **成功率（重要）**：“**很低很低。**只是阿蒙分身蕴含的一条‘时之虫’制成的‘欺瞒’符咒，能‘欺诈’到这种规律的概率很低很低”，因此他仍建议“请求‘愚者’帮助”。
- **符咒的来源（重要设定回收）**：清除贝克兰德的阿蒙分身后，“帕列斯有将制作‘**欺瞒**’、‘**寄生**’、‘**剥夺**’、‘**衰老**’四种符咒的神性符号和魔法标识经由伦纳德转交给克莱恩”，克莱恩“利用这些知识和分得的‘时之虫’，弄出了‘**欺瞒子弹**’、‘**寄生子弹**’、‘**剥夺子弹**’各一枚，后来在**对付丘纳斯·科尔格时用掉了**”。
- **克莱恩的推演（极重要，本章核心）**：
  - 他立刻回想起“那盏亮了很久的皮制灯笼：阿蒙‘欺诈’自然规律……不需要燃料也能发光一周”，并判断“**这个思路，真的只有‘偷盗者’途径的天使才能第一时间想到……未必不可行啊！**”
  - 操作细节：“虽然我已经用掉了那枚‘欺瞒子弹’，但我**可以从历史孔隙里将它召唤出来**，反正效果结束前，我肯定已重组身体，成功复活……”“自然规律真的可怜，不仅惨遭‘欺诈’，**就连用来‘欺诈’它的物品都是虚假的**……”
  - **升级方案（极重要）**：“那就是利用‘**源堡**’！”——“克莱恩怀疑‘**源堡**’同时有这三条途径的力量，只不过他本身是‘占卜家’，平时能撬动的绝大部分都集中在这个领域”；“借助‘欺瞒子弹’这个媒介，我也许可以**撬动‘源堡’另外的力量**……那‘偷盗者’途径的力量**有天使层次的威能是非常合理的推断**，唯一的问题是必须有足够层次的媒介”。
  - **具体计划（重要）**：“将一管我本身的血液赐予小‘太阳’，**构造一个超出范围的，虚假的复活点**。”“然后以‘欺瞒子弹’为触发，**推动‘源堡’内部蕴含的相应的天使层次力量，‘误导’那种规则，让它将虚假的复活点视为真正的复活点，把真正的复活点当成虚假的复活点……**”
- **阿蒙的守尸阵（极重要场景）**：“戴尖顶软帽和单片眼镜的阿蒙不知从哪里**偷来了一块石头**，将它安放在了克莱恩逝去的地方，自己则坐于上面，**耐心地玩着一只人皮手套**”；“一两千米外……**三个穿黑色古典魔法师长袍的阿蒙蹲在一块石头旁，认真地玩着不知从哪偷来的扑克牌**”；“这片荒芜旷野别的地方，阿蒙们或单独，或组团，或悠闲散步，或沉思书写，或彼此讨论着各种各样的问题”。
  - 当他试图进一步观察时，“坐在石头上的那个阿蒙忽然抬头……**荒芜旷野上，所有的阿蒙跟着抬头，望向了历史迷雾的最高处**”。
- **白银城一侧的准备（重要）**：戴里克报告“我已经得到了祝福的许诺”；科林“**明显松了口气**”，并说明自己的策略——“在那位‘愚者’突然没有了反馈的情况下，**他并未立刻倒向‘真实造物主’，决定再耐心地等待一个月**”。
  - “猎魔者”科林随即开始准备晋升仪式；他诵念的尊名是“**不属于这个时代的愚者，灰雾之上的神秘主宰，执掌好运的黄黑之王……**”
  - **“愚者”的祝福形态（重要）**：“神圣明澈的光芒里，一位**背生十二对虚幻羽翼的圣洁天使**骤然降临，在洁白羽毛飞舞飘落中，用光之翼层层包裹住了这位‘猎魔者’。”

## 二、阳谋：科林的晋升与克莱恩的复活（第26章，极重要）

- **晋升过程的异变（重要）**：“这位‘猎魔者’的身体膨胀了起来，变成了一个**灰蓝为底，青黑虬结，额头有幽黑裂缝的几米高巨人**”；“除了头部还保留着人类的模样，其余已接近神话生物”。
  - 最痛苦的阶段：“科林·伊利亚特的**头部似乎得了软骨病，整个往内凹陷，以那个幽黑缝隙为核心，缓慢蠕动起来，仿佛要形成一个星云漩涡**”；他发出“让普通生灵脑袋快要裂开精神极度混乱的嚎叫”。
  - 风险控制（重要）：“若非科林·伊利亚特已提前疏散了圆塔内的人员，**只留下半神层次的韦特·希尔蒙看守**，防备意外，此时肯定会有不少非凡者直接失控。”
- **“锚”的概念（极重要，序列3通用设定）**：六种强大生物遗骸“借助某种神秘的联系，**唤醒了这位顶级‘猎魔者’的部分回忆**”——“那是追猎一个‘魔鬼’的经历，那是**亲手结束前任首席痛苦**的攻击，那是一次次战胜强大怪物的人生”。
  - **原理（重要）**：“作为一名序列4的‘猎魔者’，**每一种强大生物的狩猎都是一场灌注了强烈精神的洗礼之战，在他生命里留下了深深的烙印**。”“借助这些强烈精神留下的烙印，他才能在服食魔药后**定位自己，不迷失于痛苦与疯狂里**。”
  - **命名（极重要）**：“这让科林·伊利亚特想起了白银城某些典籍里记载的一个名称：‘**锚**’！”
  - **通用规则（极重要）**：“**到了序列3，已算是某种意义上的神灵，可以在一定范围内回应祈祷了，也就需要一定的锚。因为还不到天使层面，锚未必是信徒，可以用别的事物替代，比如生命中那些鲜明的，有神秘学意义的烙印。**”
- **晋升结果与“祝福差异”（极重要）**：他“背后长出了虚幻光芒组成的层叠羽翼”，最终“于科林·伊利亚特体表坍陷成一副**坚固华丽却没有重量的银色盔甲**”。
  - **途径差异（重要）**：“在‘猎魔者’晋升‘银骑士’后，**因祝福神灵的不同，各自会产生少量区别**，之前的‘王庭追猎者’首领，‘弑光者’**米尔贡根得到的祝福来自巨人王，所以本身‘银骑士’领域的各方面能力都要更强一点**。”
  - “科林·伊利亚特则**偶尔能让自身凝聚的，可以‘传送’的‘银白细剑’在攻击时出现随机性的，偏好的，难以预测的变化**。另外，在‘**水银化**’时，他也能获得一定的特殊。”
  - 最终状态：“除了**头部还没长出竖直独眼**，已相当于一个神话生物”；他挥手就让白银城外一座小丘“分成两半”。
- **克莱恩的复活（极重要）**：
  - 流程：“猛地探手，从历史孔隙里召唤出了一枚子弹和‘**丧钟**’左轮”；“打开转轮，将那枚‘欺瞒子弹’塞了进去”；“借助神秘学联系，**隔空瞄准了他原本的死亡地点**”；“砰！他冷静地扣动扳机”；同时“**纯凭自身意念，撬动了‘源堡’的力量**”。
  - 落地：“他拿着‘丧钟’左轮的历史投影，模拟出失重急坠的感觉，‘跃’向了代表‘太阳’的那颗深红星辰，‘跃’向了那一小管自身血液。”
  - 复活场景：“戴里克接收的那根金属细管随之自行破碎，**鲜红的血液从中浮出，漂到半空，不断裂变，与光之碎片们结合在了一起**”；两三秒后“化成了一团巨大的光球”，再“勾勒出了一道人影”——“**正是格尔曼·斯帕罗**”。
- **阿蒙的推断（极重要）**：荒芜旷野上的阿蒙们“齐齐抬头，望向了高空划过天际的闪电”，随后“哑然片刻后失笑道：‘**他不像是能想出这种办法的人……帕列斯？祂加入了这个以塔罗牌为代号的组织？**’”
- **克莱恩对“为何如此顺利”的分析（极重要）**：
  - “**在白银城，阿蒙顶多有一些序列4序列3层次的分身**，克莱恩可以预先用‘真实视野’找到他们，进行清除。”
  - “而如果他们能组合成序列2层次的分身，已初步掌握‘源堡’……的克莱恩完全可以**在灰雾之上与这分身做一次争斗，且立于无法被攻击到的不败之地**。”
  - “若是阿蒙将本体移到了白银城，那克莱恩就能选择在原本的死亡地点复活。”
  - **关键数值（极重要）**：“当然，阿蒙可以制造近乎序列1的分身，将祂派到白银城，但是，**非凡特性守恒这个前提下，祂又能弄出几个这种层次的分身？不会超过两个！**”
  - **多复活点策略（极重要）**：“而克莱恩可以**将存留的血液分成多个部分，利用赐予仪式，将它们送至‘倒吊人’先生那里，送至‘隐者’女士那里，送至‘星星’伦纳德那里**，有太多太多的复活地点可供选择，阿蒙根本看守不过来。”
  - 他的定评：“**这是凭借自身层次、非凡能力和‘源堡’特殊做出的光明正大的谋划**”——即本章标题的“阳谋”。
- **一处轻松的收尾（人物素材）**：戴里克问“‘世界’先生，需要带点食物吗？有可以制造牛奶的蘑菇！”——克莱恩“控制住自己，没让嘴角出现抽搐”，回答“**我不喝牛奶。**”

## 三、代问：向威尔与阿罗德斯求问“奇迹师”主材料（第27章，极重要）

- **阿蒙的反向定位（重要）**：“阿蒙们分别站在不同的地方，张开嘴巴，用巨人语诵念道”格尔曼·斯帕罗的完整尊名，“隔了十来秒钟……低声笑道：‘**改得真快。**’”
  - **克莱恩的反制（重要）**：他“在灰雾之上就将默许为可以自动回应的那个尊名改了一段，**从‘贝克兰德魔术和戏剧表演的保护者’变成了‘贝克兰德所有贫困孩子的保护者’**——这来源于他设立的‘鲁恩慈善助学基金’”。
  - 更进一步的决定（重要）：“他让**每一条‘灵之虫’都只能倾听祈祷，无法主动回应**，除非已得到本体意识的允许。”
- **他对诺斯遗迹的顾虑（极重要）**：“既然阿蒙已经在神弃之地游荡了一千多年，且来过白银城附近，那祂怎么可能不被吸引到北方遗迹诺斯？”“**能让白银城那位首席都不敢进入，诺斯城内的力量绝对已经达到了天使层次**”；“就算以前没这么做，现在也肯定在往那边赶”；也有另一种可能：“**当初白银城首席第一次去那里的时候，诺斯遗迹还没这么危险**……**祂本身在不断迁徙，就为了躲避阿蒙？**”
- **诵读神灵真名的实验（极重要）**：
  - 他先记录了三段式祈祷的规则：“**神灵的尊名往往不止三段，但诵念时挑选其中三段就行了**，比如，‘永恒烈阳’的完整尊名是‘**永恒烈阳，不灭之光，秩序化身，契约之神，商业守护者**’。”
  - 结果：他依次向“风暴之主”、“知识与智慧之神”、“黑夜女神”祈祷，“**可是，足足一刻钟过去，他周围都未发生半点变化。**”
  - 他的推测（重要）：“**在神弃之地向序列0真神祈祷无效？除非目标是‘真实造物主’，或者掌握有‘源堡’‘混沌海’等事物的存在？**”“也许是因为神弃之地残余着多种神力……**不同神灵的真名有着特殊的神秘学意义，可以撬动相应的力量**？”“这样就能解释白银城一直在教授巴德海尔、赫拉伯根这两个真名，却没有与‘战神’、‘知识与智慧之神’建立起联系的原因……”
  - 他的自我克制（人物素材）：“我先前的想法简直就等价于：**我有两天没作死了，今天得认真作一作！**”
- **向威尔·昂赛汀提问（极重要）**：
  - 他直接点燃纸鹤联系失败：“**果然不行……**”
  - 他改由具现“世界”向“愚者”祈祷，请祂把要求转给“正义”小姐；奥黛丽在梦中见到“一条**银白色的巨蛇**。这巨蛇**没有鳞片，身上布满符号和花纹，它们形成了一个又一个彼此相连的，有不同标识的转轮**”，并以“鲜红而冰冷的眼睛”开口。
  - **威尔的第一个关键答复（极重要）**：“**不同途径的序列2在数量上有所不同，‘诡秘侍者’满额的情况下，‘奇迹师’只能有六位。**”

## 四、我有个眷者：六份“奇迹师”特性的下落（第28章，极重要）

- **威尔的完整说明（极重要，逐条）**：
  1. “**密修会首领查拉图服食的序列1魔药来自一位‘诡秘侍者’，也就是说，他多占有了一份‘奇迹师’非凡特性**”；
  2. “同样的，当初那位**安提哥努斯家族先祖**也是，当然，他们如果有青睐的，愿意培养的目标，作为一名位格足够高的天使，**可以自行分割出多余的‘奇迹师’非凡特性给对方**”；
  3. “第三份‘奇迹师’非凡特性与来历神秘的特性结合，**成为了封印物‘0-05’，这又叫‘许愿神灯’**……**曾经有真神试图摧毁这件物品，让特性分离，各自重聚，结果未能成功**”；
  4. “第四和第五份‘奇迹师’非凡特性分别以‘0’级封印物的形式存在于‘**永恒烈阳**’和‘**风暴之主**’教会，一个代号‘**0-13**’，源自**第三纪那位造物主**，叫做‘**最后的盛宴**’；一个代号‘**0-32**’，是‘**四皇之战**’的产物，名为‘**永不落幕的剧场**’”；
  5. “**第六份‘奇迹师’非凡特性也许在神弃之地**，第三纪时，有一头残存的‘**乌黯魔狼**’偶尔出现，**大灾变后就完全失去了踪迹**。”
- **奥黛丽的自主追问（重要）**：她指出“序列1的‘诡秘侍者’您只提了密修会首领查拉图和安提哥努斯家族的先祖，似乎并不满额”，威尔的回答是：
  - “确实，**‘诡秘侍者’满额应该有三位**。”
  - “但在第二纪，**在古神弗雷格拉还存活的年代，第三份‘诡秘侍者’非凡特性就形同失踪**，没有哪位存在知晓它的下落，它对应的那份‘奇迹师’非凡特性同样如此，**也许已经与它结合，也许找到了足够隐蔽的办法，藏好了自己**。”
- **威尔的“眷者”与尊名（极重要）**：他索要的报酬是——“我有一位眷者，是杰出的**美食家**，他有个心愿，想品尝一下**各个贵族家庭的冰淇淋**，评出最美味的那种。”
  - 其眷者的尊名（重要）：“**幸运的化身，预知未来的怪物，传播厄难的灾祸，贝克兰德所有命运的见证者，混乱与疯狂的看守。**”
  - 奥黛丽的观察：“这个尊名和正常的序列3尊名有一些区别啊，**最后竟然没有名字**……”
  - 克莱恩的评价（极重要）：“‘**混乱与疯狂的看守**’……这应该不是‘命运之蛇’的尊名，而是祂**序列3时使用过的**……‘怪物’途径看守混乱与疯狂？或者**说，在这个世界里，哪怕命运，底层也是混乱与疯狂的，‘怪物’们在努力对抗着这些，让一切显得正常**？”
- **克莱恩对各条路径的排除（极重要）**：
  - 查拉图：“**就不用想了，祂不可能分割给我，祂只想把我变成祂的秘偶**……”
  - 安提哥努斯：“可这样一来，又得求女神了……而且，**女神未必拿得出来**，祂之所以要封印那失控的半个‘愚者’，或许就是因为**无法杀掉祂，一旦杀掉，这位就能摆脱当前困境，于某个地方复活重生**……这种情况下，女神是没法直接从安提哥努斯那里分离‘奇迹师’非凡特性的……”
  - “0-05”：“**连真神都没法粉碎的‘0-05’也不用想了，得到也没法用**……这件封印物的来历真的很神秘，很有问题啊……”

## 六、整合包可用要点小结

- **机制**：“欺诈”规则（比欺诈天使容易，因世界底层是疯狂与混乱）；符咒四种（欺瞒、寄生、剥夺、衰老）；序列3的“锚”可以用生命中带神秘学意义的烙印替代信徒；银骑士因祝福神灵不同而产生能力差异。
- **“0”级封印物**：“0-05”许愿神灯、“0-13”最后的盛宴（永恒烈阳教会，源自第三纪造物主）、“0-32”永不落幕的剧场（风暴之主教会，四皇之战产物）。
- **神灵尊名**：永恒烈阳＝“永恒烈阳，不灭之光，秩序化身，契约之神，商业守护者”；威尔的眷者尊名“幸运的化身，预知未来的怪物，传播厄难的灾祸，贝克兰德所有命运的见证者，混乱与疯狂的看守”。
- **组织**：“命运隐士会”（雅各家族宝藏）、军情九处（含“异常事务法庭”）。
