## 一、本卷三条主线

### 主线甲：晋升与“扮演”的再学习
- 【事实】卢米安入图铎宝库取“不老魔女”材料 → 与“镜中人”和解 → **成为“不老魔女”**。
- 【事实】紫焰巨鸟来投 → 班西港一战 → **晋升“天气术士”（序列 2）**。
- 【事实】“扮演守则”逐条被验证：**“不老”重在时间厚度**（奥萝尔是几万年前的人）；**“天气术士”重在“被看见”与“仪式感”**，且暗含“以天气带来灾难”。

### 主线乙：“病教”与“双神”
- 【事实】击杀莫科西多斯 → 借“愚者”切割信仰线条为闭环 → 造出“**瘟疫之神**”与“**疾病之神**”两个名号。
- 【事实】卢加诺、利昂这条线把“病教”转为可治理的组织：**教宗（简娜）→ 主教 → 神甫**，戒律是“不得公开传教、允许兼信正神”。

### 主线丙：特殊镜中世界与“图铎—奇克”的旧账
- 【事实】镜中罗塞尔退场、留下“三句话”与“魔女”牌 → 路易斯·古斯塔夫失踪 → 第四纪特里尔 → **“原初魔女”奇克现身**。
- 【事实】奇克自述：图铎真正的复活布置在她手里；她和图铎在特殊镜中世界深处造出了“**镜中的最初造物主**”。
- 【事实】卷末：欧弥贝拉真正降生 → “永恒烈阳”等于“原初上帝”的象征被强化 → **“黑夜女神”斩杀奥赛库斯** → 八颗星辰压向屏障 → “愚者”以符号撑住 → 绯红之月沉入屏障之内。

## 三、须改标的条目（重要）

1. **【须改标】“欧弥贝拉是‘伟大母亲’之女”**
   第八十章【事实】给出真正父母：**母为“母巢”、父为“原初上帝”**。此前“伟大母亲之子”的说法须按“母巢是从‘伟大母亲’身上撕下的一半”重读。

2. **【须改标】“永恒烈阳只是被利用的真神”**
   第八十一章【事实】其体内早有“原初上帝”的意识复苏，长期压制、维持脆弱平衡；最终**主动求死**。此前按“纯粹受害者”处理的定性须放宽。

3. **【须改标】“灾祸需要远离母亲”的字面理解**
   第八十章【事实】其真意是“**你就是母亲——孕育欧弥贝拉的母亲**”，而非“避开普阿利斯”。这是本卷最重要的一次误读修正。

4. **【须改标】“狩猎隐匿贤者的凶手只是‘愚者’”**
   第八十一章【事实】“黑夜女神”早在大灾变时便有猜测，**借“注定的疯狂”确认**——这件“0”级封印物的作用由此交代。

5. **【须改标】“魔女教派只是敌人”**
   第七十章起【事实】芙兰卡与克拉丽丝、妮塞娅的周旋表明：教派内部并非铁板一块，**“茱蒂丝—克丽丝芒娜”这条姐弟线**是另一条入口。

6. **【须改标】“简娜只是小队第三人”**
   第七十五章【事实】她是“故事作者”安排好的**牺牲品与关键变量**；第七十七至七十八章【事实】她的碎片已与卢米安融合，存在于其右肩那颗脑袋上。此后不宜再按“独立行动者”记录。

7. **【须改标】“卢米安是完整的人”**
   第七十八章【事实】他目前是**三首之身**：左肩戴暗金面具（奇克＋图铎两面）、右肩（奥萝尔＋简娜两面）。此后的行动主体须标注这一状态。

## 四、本卷新确立的“可用规则”（择要）

1. **扮演守则不可想当然**：“不老”重“时间厚度”，“天气术士”重“被看见”与“仪式感”。
2. **恩赐＝可回收的污染**：上位者收敛不全会让受赐者当场怪物化。
3. **转途径有隐藏条件**：缺失序列会带来额外的“暗含仪式”。
4. **“0”级封印物可当武器**：两大教会以封印物而非天使进入第四纪特里尔，因“鲜血之井”序列越高越危险。
5. **“言说即污染”**：伟大存在的真实尊名难承受，“神之信使”以“被污染”换取“能念尊名”。
